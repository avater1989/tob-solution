# 艺博 To-B 获客解决方案 · MVP 原型与 PRD

面向内部评审：双端可点击 HTML 原型 + MVP PRD。核心命题是**几个 IP 快速上线可用**。

## 怎么打开

用浏览器直接打开：

[`prototype/index.html`](prototype/index.html)

即可进入导航页，再分别进入：

- **商家管理端**：`prototype/admin/dashboard.html`（布局见 [`docs/DESIGN.md`](docs/DESIGN.md)：顶栏模块 + 左侧二级 + 主区 + 右侧助手）
- **SCRM 概览**：`prototype/admin/scrm-overview.html`
- **C 端 To-B 小程序模拟**：`prototype/miniprogram/home.html`

无需安装依赖、无需本地服务器（若浏览器限制本地 `file://` 脚本，可用任意静态服，例如 VS Code Live Server）。

## MVP 范围摘要

| 板块 | 本期 |
|------|------|
| 公域 | 并入 SCRM，仅视频号 |
| SCRM | 线索、期次分配、视频号商品/订单、直播促到（短信为主） |
| 直播 | 独立小程序路径、创建/审核、直播间购课 |
| 内容 | 线上课上下架排序，固定首页模板 |
| 交易 | 订单与权益开通/回收示意（备付金分账） |
| 用户 | 列表、详情、手动标签 |
| 看板 | 获客 / 直播 / 转化 |

不做：抖店完整链路、广告投放、H5 直播主路径、艺博士/定制化/测评、读书会、完整分账对账、企微服务商改造页等（详见 PRD §3.1）。

## 10 分钟内部评审演示脚本

顶部「评审路径」可随时跳转。建议顺序：

### 1. 开场（1 min）

打开 `prototype/index.html`，说明：双端原型 + PRD 对齐「IP 快速上线」，不是完整七大板块。

### 2. 路径① 内容售卖（2 min）

1. 管理端 → **内容课程** → **创建课程**（看字段：单课/系列、试看目录、上下架）
2. 点 **预览 C 端首页** → 点进课程详情 → **立即购买** → 支付成功 → **我的 / 学习**

### 3. 路径② 直播转化（2.5 min）

1. 管理端 → **直播** → 看审核态与「直播作商品」
2. **创建/编辑直播** → **预览直播间**
3. C 端直播间：评论、挂载课购买、未购买门票 → 支付结果回直播间

### 4. 路径③ 视频号承接（2 min）

1. 管理端 → **视频号商品**（关联与领课配置）→ **视频号订单**
2. 对短信失败单点 **重发短信** / **领课链接**
3. 进入 C 端 **领课页** → 领课成功 → 加微示意 → 去学习

### 5. 路径④ 私域运营（2.5 min）

1. **SCRM 概览**：线索概览与简报  
2. **分配规则**：推广期次 + 渠道×商品×期次  
3. 侧栏按现网结构：客户中心 / 公域获客 / 营销管理 / 工单中心 / 内容中心 / 业务设置  
4. **直播促到** → **用户详情**打标 → **看板**

### 6. 收口（0.5 min）

对照 PRD「非目标」与「后续迭代映射」，确认试点 IP 上线边界，避免范围回潮。
