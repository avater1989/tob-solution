================================================================
艺博 To-B 原型服务 - 手动启动指南
================================================================

如果双击 .bat 文件后浏览器显示 404，请按以下步骤手动启动：

----------------------------------------------------------------
方法 1（推荐）：用 PowerShell 直接运行
----------------------------------------------------------------
1. 在项目根目录地址栏输入 powershell，按 Enter
   （项目根目录就是包含 启动原型服务.bat 的那个目录）

2. 在 PowerShell 中粘贴并执行：

   python -m http.server 8765

   如果报错找不到 python，试试：

   py -3 -m http.server 8765

3. 看到 "Serving HTTP on 0.0.0.0 port 8765" 后，
   打开浏览器访问：

   http://127.0.0.1:8765/prototype/index.html

4. 想停止服务：在 PowerShell 窗口按 Ctrl+C

----------------------------------------------------------------
方法 2：用 CMD
----------------------------------------------------------------
1. 在项目根目录地址栏输入 cmd，按 Enter

2. 执行：

   python -m http.server 8765

3. 浏览器访问 http://127.0.0.1:8765/prototype/index.html

----------------------------------------------------------------
方法 3：VS Code 内置服务
----------------------------------------------------------------
1. 用 VS Code 打开项目根目录
2. 安装 "Live Server" 扩展
3. 右键 prototype/index.html → "Open with Live Server"
4. 浏览器会自动打开 http://127.0.0.1:5500/prototype/index.html

================================================================
常见错误
================================================================

错误: "python 不是内部或外部命令"
  → Python 没装或没加到 PATH
  → 解决：从 https://www.python.org/downloads/ 下载安装时
          勾选 "Add Python to PATH"

错误: 地址栏打不开 powershell
  → 用文件资源管理器导航到项目根目录
  → 在路径框（显示 C:\share project\...）直接输入 cmd 然后回车

错误: 端口 8765 已被占用
  → 改用其他端口：python -m http.server 8888
  → 然后访问 http://127.0.0.1:8888/prototype/index.html
