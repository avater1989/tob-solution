建议 10 分钟评审顺序（4 条主路径）

  1. 内容售卖：管理端 内容课程 → 创建课 → 切 C 端首页购买 → 我的可学
  2. 直播转化：管理端 直播 → 创建/审核态 → C 端直播间购课
  3. 视频号承接：管理端 视频号订单 → 重发短信 → C 端 领课页
  4. 私域运营：SCRM 线索池（分配/渠道对接）→ 跟进管理 / 直播促到 → 看板
