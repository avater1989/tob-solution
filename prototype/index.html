建议评审顺序（9 条主路径）

  1. 租户开通：运营端 租户列表 → 开通租户 → 租户配置（角色权限 / 收银账户 / 营销额度）
  2. 内容在小程序售卖：管理端 内容资产 → 创建课 → 商品管理 创建商品 → 首页装修上架 → C 端商品详情 → 收银台 → 权益自动发放
  3. 内容通过微信小店售卖：管理端 微信小店商品 授权与同步 → 关联商品 → 订单列表可见「微信小店」渠道 → 权益自动发放
  4. 直播售卖：两种方式 —— 先建直播后卖门票（创建直播时设「付费观看资格」）／ 先卖商品门票后建直播（挂载商品不自动含观看资格）
  5. 直播转化：创建直播 → 平台准入审核（运营 · 审核工作台）→ 挂载商品 → C 端直播间购课 → 订单 → 权益发放
  6. 私域运营：SCRM 线索池 → 跟进管理 → 直播促到（预约与开播提醒）
  7. 商家额度扣减：运营端 租户配置 · 营销额度 调整 → 商家端 营销额度 查看短信与直播人次扣减流水（只读）
  8. 订单对账结算：订单列表 → 对账（T+1 自动）→ 结算（商家确认 → 财务复核 → 打款）→ 提现
  9. 数据分析及复盘：管理端 经营总览 / 期次复盘；运营端 数据看板（商家经营 / 期次 / 健康度）
