微信小店授权步骤

  1. 使用微信小店「店长」微信登录微信小店后台，进入「服务市场 → 经营工具 → 我的服务」，获取 小店ID 与 授权密钥；
  2. 回到本页点击「+ 授权微信小店」：第一步填写小店信息；第二步把弹窗给出的 服务器地址 / Token / 消息密钥 填到小店后台「服务市场 → 消息推送」，完成授权。
