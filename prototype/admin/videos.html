微信小店授权步骤

  1. 使用微信小店「店长」微信登录微信小店后台，进入「服务市场 → 经营工具 → 我的服务」，获取 小店ID 与 授权密钥；
  2. 回到本页点击「+ 授权微信小店」，填写小店信息并完成授权；
  3. 在本页「小店设置」中开启消息推送，将回调信息填入微信小店后台；
  4. 微信小店绑定橱窗（见下方指引）；
  5. 授权完成后可在下方「商品管理」批量上架课程商品（商品需选择「无需配送」）。

微信小店绑定橱窗步骤

  1. 点击链接进入 视频号助手，用微信小店店长微信登录；
  2. 进入「直播 → 直播管理 → 开放能力」，查看 橱窗ID 与 橱窗密钥；
  3. 回到本页点击对应店铺的「绑定橱窗」，填入橱窗ID与密钥；
  4. 绑定成功后，课程审核通过可自动上架橱窗；未绑定则需手动上架。
