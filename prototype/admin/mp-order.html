按 C 端订单页的真实结构配置展示。C 端订单页固定为三部分：状态筛选（全部 / 待付款 / 已完成 / 已退款）→ 订单卡（订单号 + 状态标签 + 封面 + 标题 + 规格 + 价格 + 下单时间 + 按钮组）→ 空态。此处只配置端上真实存在的文案与展示项，订单数据与退款处理在交易模块，配置后 C 端即时生效。

状态筛选

对应 C 端订单页顶部的状态 tab，端上固定为这 4 项
端上状态 端上显示名称 是否展示 状态 操作
端上固定这 4 个状态，状态由订单实际流转决定，此处只改展示名、不能新增状态；「全部」为端上固定项，不可删除。

订单卡展示字段

对应 C 端订单卡的各个展示项，逐个开关
关闭某项后，C 端订单卡不再渲染该字段；商品标题与封面为订单卡必需项，不可关闭。

按钮文案

对应 C 端订单卡右下角的按钮组，按订单状态分组
所属状态 按钮文案 是否展示 状态 操作
按钮的实际可用性由订单状态决定（如「去支付」仅在待付款订单出现、「看回放」仅在已完成的直播订单出现），此处只配置端上展示的文案与开关。
