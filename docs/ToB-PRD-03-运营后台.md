## 2. 内容

### 2.1 平台内容生产（P0）

与商家端内容三形态同构（`content-series/video/article(+edit/detail/outline)`、`content-category`），差异点：

- **定位**：平台标准内容库；生产后可下发/授权给租户（商家端呈现为「平台来源」只读内容）。
- **系列课编辑**：内容信息（名称*45 字、分类、简介*256、富文本）+ 商品信息（获取方式 免费/付费/指定用户、价格、分组、访问密码、有效期、上架策略 立即/定时/暂不、店铺显示）+ 分享设置；「保存并进入目录」。
- **目录**：章节弹窗（章节名*、视频名*、时长、视频来源*[引用不上传]、必修/试看）；已上架只读。
- **视频库**：状态含「转码中」（进度条）；来源 mp4/mov ≤2GB 或引用。
- **分享**：短链 `yibo.app/s/{id}` + 二维码。
- **规则 R-OPS-C-010**：平台内容变更后对已下发租户的同步策略（实时/次日）为 `来源:产品补全`，建议次日生效并保留租户侧上下架状态。

### 2.2 测评管理（P1）

与商家端测评同构（`assess-*` 全套）；差异：`assess-results.html` 为**跨租户**结果查询（筛选含租户）；报告组件同 5 枚举。

### 2.3 平台审核工作台 `audit.html`（P0）

- **审核范围（R-OPS-A-010）**：直播**必审**；系列课/视频/图文**上架前必审**；服务类商品**抽审**。通过后发布 C 端。
- **队列**：4 类内容 + 直播；示例（亲子沟通训练营 ¥299/21 节含试看 2、视频 ¥69 试看前 3 分钟、图文 ¥39、服务卡 ¥199）。
- **统计卡**：待审数、今日已审（通过/驳回）、平均时长（SLA 4h）、驳回率。
- **批量通过**：勾选 + confirm。
- **驳回原因枚举（R-OPS-A-020）**：A-03 宣传绝对化承诺 / B-01 涉嫌侵权 / C-02 封面与内容不符 / D-05 直播信息不完整 / 其他（须填说明）；**驳回说明必填**；通知商家修改重提。
- **通过弹窗**：备注选填、商家可见；操作入审核记录与日志。
- **裁决 Q-12 附注**：`audit-records` 类型筛选须补齐 5 类型（线上课/视频/图文/商品/直播）。

### 2.4 审核记录 `audit-records.html`（P0）

- 审核历史（人/时间/结论/说明）、通过率统计；**申诉入口**：已驳回行「申诉」→ 登记申诉进复核队列；统计卡「商家申诉 N，待复核 M」；申诉结论回写审核记录。

## 3. 交易与结算

> 费率口径唯一基准见商家端分册 §6.2（入金 0.3% / 链路 A 佣金 20% / 链路 B 服务费 0.6%）；资金链路=通联托管代收/代付 + 银行弱存管（通联+艺博+招行），D+1 结算，提现时点 T+1 日 14:00（R-OPS-T-000）。

### 3.1 收款与进件

#### `pay-channels.html` 收款与清分（P0）
- 收单渠道：通联云商通（启用）/ 微信直连（备用未启用）。
- **收款主体**：按省 4 家子公司（名称不含「教育」）；进件状态（已通过/进件中）；资金归集存管账户。
- 商户号管理：通联商户号/账户集（中间账户集 10004 托管代收）/ 结算周期 D+1。
- 费率声明卡：入金 0.30%、服务费 0.60%、佣金 20%、提现 1 元/笔、实名认证 5 元/次、云商通年费（年流水 ≥5000 万免，否则首年 3 万/次年 2 万）；**废弃口径声明**：1%/2%/10%/12%/15%/5%/0.28%。

#### `onboard-audit.html` 进件审核工作台（P0）
- 链路：商家提交→平台初审→通联审核（工商+法人实名+OCR）→通过→绑定手机→提现协议签约→可收款。
- Tab：待初审 / 通联审核中 / 已通过·已驳回。
- 审核抽屉：主体信息（memberType 企业=2/个人=3、统一社会信用代码、法人）、影印件 OCR 校验表（营业执照/身份证正反面必传、开户证明非必传、≤1MB JPG/PNG）、结算卡、时间轴；操作「初审通过并转通联」。
- **驳回枚举（R-OPS-T-010）**：资料不齐 / OCR 不一致 / 结算卡主体不一致 / 执照过期 / 其他；驳回后商家端 onboard 进入「驳回待修改」。
- 审核要点弹窗：工商八要素核对清单。

#### `pay-members.html` 通联会员管理（P0）
- bizUserId ↔ userId 一一对应；列：memberType、绑定手机、进件状态、**签约状态**、默认分账比例（自建 99.4% / 平台内容 20%）、提现方式。
- 约束：未绑手机不能创建订单、未签约不能提现；详情含 ContractNo；结算卡变更需重审；「催签约」动作。

### 3.2 结算规则 `settle-rules.html`（P0）

- **命中优先级（R-OPS-T-020）**：商品 > 商品分组/类目 > 租户/套餐/合同 > 全局默认；同一订单仅命中一条。
- 规则列表：名称、内容来源（链路 A/B）、费率、账期、状态；示例含老师 5%/推广人 8% 多级分账。
- 弹窗字段：规则名称*、优先级*（5 级）、适用范围*（全局/分组/类型/指定租户/单商品）、内容来源*（链路 B 服务费 0.6% / 链路 A 佣金 20%）、平台费率方式（分账中扣/先分后结——「先分后结」无示例覆盖，`来源:产品补全` 补演示）、账期*（T+1/T+7/周结/月结）、先票后款（否/是）、结算门槛、最低留存；分账方表（通联会员号+比例，须已进件+签约）。
- **强校验（R-OPS-T-030）**：分账比例合计=100%（实时红绿，保存阻断）；修改仅对之后支付订单生效（历史按快照）。
- 试算弹窗：金额→入金手续费 0.3% 单列→链路 B 商家 99.4%/平台 0.6% 或链路 A 商家 20%/艺博 80%。
- 账期独立于通联手续费扣费周期；门槛未达顺延；留存不参与结算与提现。

### 3.3 对账（P0）

#### `recon.html` 对账管理
- **规则（R-OPS-T-040）**：每日 T+1 02:00 拉取通联/视频号小店账单，按渠道交易单号逐笔核对；全部一致→「已对平」→**待商家确认**；商家确认后进结算池；**商家申诉暂停该账期结算**。
- 双 Tab：对账单列表 / 差异工单。
- 对账单状态机：待对账→已对平/有差异→待商家确认→已确认/商家已申诉。
- 列：账期、渠道、交易额、退款、服务费、应结算、差异笔数、状态；操作：催确认/详情。

#### `recon-detail.html` 对账单详情
- 金额构成（应结算=交易额−退款−服务费−其他分账方分成）+ 订单级明细 + 确认与申诉时间轴（商家确认人/时间）。
- **裁决 Q-02**：列表页演示金额与详情计算不一致为旧口径残留，实现以公式为准。

#### `recon-diff-detail.html` 差异工单
- **差异 5 类型（R-OPS-T-050）**：金额不一致、平台/渠道单边账、退款状态不一致、重复支付、跨期差异。
- 责任人自动分派（按类型→结算组/风控组）；**SLA 24h，超时升级高优并通知负责人**。
- 记录对比：平台记录 vs 渠道记录（单号/金额/状态）。
- **5 种处置动作（R-OPS-T-060）**：重取渠道账单 / 人工确认（按渠道金额并入本期）/ 补单修复（生成缺失订单纳入本期）/ 补差调账（调整至指定账期）/ 挂起（下期跟踪）；另有结案（结案后对账单重算）。
- 举证附件：渠道账单 xlsx（系统自动）、回调日志 txt（人工上传）；下载留痕。
- 工单状态机：待处理→处理中→已平账/已补差/已挂账/已关闭。

### 3.4 结算（P0）

#### `settlements.html` 结算管理
- **生成条件（R-OPS-T-070）**：对账已对平 + 无未结差异 + 达结算门槛 + 商家已确认。
- 列：结算单号、租户、账期、交易额、退款、服务费、应结算、状态；操作：详情/批量确认/批量复核/批量打款。

#### `settlement-detail.html` 结算单详情
- 状态机：待商家确认→已确认→待财务复核→打款中→已打款→已完结；异常：已退回（复核驳回附原因）/结算暂停（申诉或资金冻结）。
- 金额构成 + **分账明细**（以通联回盘为准：商家 MEM-* 99.4% + 艺博 TL-MCH-* 0.6%，或链路 A 20/80）。
- **双人复核（R-OPS-T-080）**：打款需第二人复核，**提交人≠复核人**；记录复核人/时间/凭证；「先票后款」开启时无有效发票不得打款。
- 商家确认信息、收款账户、打款凭证、完整时间轴；打款失败保留原单重试。

### 3.5 提现审核 `payouts.html`（P0）

- 列：提现方式（自动/手动）、金额、可提现余额、到账账户、**风控标记**、状态。
- 状态机：待审核→审核通过→打款中→已到账；已驳回（原因必填）；打款失败（可原单重试）。
- **风控联动（R-OPS-T-090）**：命中风控标记（如退款率超标/结算卡不一致）或未结差异 → 强制人工审核，不自动放行；批量通过仅作用于无标记单。
- 审核弹窗：单号/金额/余额/账户（只读）+ 审核备注；规则：金额≤余额（扣冻结与最低留存）、卡须同主体进件账户、超限转人工、打款中冻结金额。
- 详情抽屉：余额构成（已分账到账−已提现−提现中−冻结=可提现）+ 时间轴 + 打款凭证。

### 3.6 财务（P1）

- `invoices.html` 发票管理：Tab 方向（平台→商家/商家→平台）；新建开票申请（方向*、租户*、类型*[专/普]、关联结算单、开票主体*、税号*、金额*[≤关联结算单服务费/应结算额]、先票后款）；红冲（原因*，关联结算单标待复核，已打款走资金追偿）；状态机：待开票→开票中→已开票→已寄出→已签收/已作废/已红冲。
- `fee-ledger.html` 服务费台账：收入=佣金(20%)+服务费(0.6%)，退款按账期冲减；趋势、租户 Top5、渠道结构、明细（账期×租户×分组×渠道，含结算模式·费率、平台收入、开票/到账状态）；导出。
- `invoice-settings.html`（P0，平台配置）：买家开票（主体/类型/金额口径/90 天时限）；平台与商家互开规则（链路 A：商家→艺博佣金发票、不先票；链路 B：艺博→商家技术服务费发票、**先票后款**；手续费发票）；红冲规则（需财务复核/直接红冲；红冲后结算单待复核/暂停该租户结算）。

### 3.7 资金风控 `fund-risk.html`（P1）

- 监控水位卡：备付金/退款率/分账失败/提现频次/未结差异/账期占用。
- 风控规则表：名称*、监控项*（退款率 7 日/提现次数/分账失败/备付金/差异笔数/账期占用）、阈值*+单位、触发动作*（仅告警/限提现/转人工/暂停结算/暂停分账）；**变更仅对之后行为生效**。
- 拦截与预警记录 → payouts/recon 联动。

### 3.8 平台配置（P0，承接商家端下架页）

- `trade-settings.html` 交易选项（平台默认值）：下单（合并下单+可调范围）、订单与支付（关单时间/权益开通时机/有效期/退款时限）、退款（未使用可退、按比例退款开关、超时自动同意、权益回收）、评价。
- **平台级不可关闭约束（R-OPS-T-100）**：绑定手机才能下单、未签约不能提现、当日退货额≤当日交易额且≤余额。
- `invoice-settings.html` 见 §3.6。

## 4. 系统管理

### 4.1 平台自身（P0）

- `sys-users.html`：账号（筛选含角色/状态）；新增（账号*、姓名*、手机*、部门、职位、角色*、初始密码 Ops@123456 **首登强改**）；超管仅限现有账号、不可停用；重置密码（8-20 位字母+数字、登态失效）；同步用户（SSO/企微/人事，增量、手机去重、同步后默认停用）。
- `sys-depts.html`：三级树（中心/部门/小组：平台运营中心、风控审核中心、财务结算中心、数据中心）；三级不可再加子级；删除先转移用户。
- `sys-roles.html`：内置仅超级管理员（不可改）；自定义：租户管理员/审核专员/结算专员/数据专员/值班运营/只读访客；权限=模块×（查看/编辑/审核/导出）矩阵 + 数据范围（全部/指定租户/本人）；资源标识如 `audit:queue:approve`。
- `sys-resources.html`：平台资源树（5 模块 22 资源）；类型（模块/页面/按钮/接口）；**敏感标记**（租户导出/结算确认）；绑定角色。
- `sys-dict.html`：数据字典（左类型右字典项）；类型（编码唯一不可改、内置不可删）；字典项（标签*、键值*、排序、标签样式、状态）；枚举如 tenant_status/audit_result/settle_status。

### 4.2 租户治理（P0）

#### `tenants.html` 租户列表
- 状态机：**待开通（注册留资线索）→ 试用中（14 天）/ 正常 → 已到期 → 停用**；续费顺延。
- 开通弹窗：租户名*、公司*、套餐*、服务费率*、管理员*+手机*（正则）、初始密码 Yb@123456。
  - **裁决 Q-01**：费率枚举统一为「0.6%（默认）/ 0.3%（战略）」，废弃 1%。
- 停用：confirm + 原因枚举（到期未续/违规/主动/其他）；**效果（R-OPS-T-110）**：后台只读 + C 端全部下架 + 未完结结算继续走完；可恢复。
- 续费：套餐+时长（1 年/2 年/3 个月），到期顺延费率不变。

#### `tenant-detail.html` 租户详情
- 基本信息（含服务费率）、应用绑定（MERCHANT_ADMIN + C_MINIPROGRAM）、关联角色（模板下发内置角色）、商家账号列表、租户用户/部门/角色入口。

#### `users.html` / `tenant-depts.html` / `tenant-roles.html` / `user-detail.html`
- 租户用户：账号=手机号；新增（账号*、姓名*、租户*、部门、角色*、初始密码 Yb@123456）。
- 租户部门：按租户切换看组织树。
- 租户角色：内置角色（模板下发，不可删）+ 商家自建；数据范围（全部/本部门/本人）；敏感操作（解密留痕/退款审核/结算确认）；新增可「从模板复制权限」；停用=成员只读。
- 用户详情：手机号**解密留痕**；多租户绑定卡（已解绑含时间）；登录与操作记录（密码错 5 次锁定、平台解锁留痕）；停用（踢会话）/删除（不可逆，优先停用）。

### 4.3 角色模板与应用资源（P0）

- `template-roles.html`：7 个商家侧模板角色（TPL_MCH_*）；应用范围按套餐限定；状态机：草稿→已发布→已下线；**变更仅影响新开通租户，存量需单独同步**；复制为新草稿。
- `apps.html`：应用管理（商家后台/C 端小程序/视频号助手/OpenAPI/企微 SCRM）；应用状态机：已下架→灰度中→已上架；授权管理（套餐默认授权 / 单独授权 / 试用[至指定日] / 取消授权——取消后入口隐藏、接口拒绝、**数据保留**）；版本记录。
- `resources.html`：商家侧功能资源树（trade/content/user/scrm/openapi 19 资源）；敏感资源（结算确认、手机号解密）留痕；绑定角色跨租户内置角色+单租户自定义角色。

## 6. 治理闭环与验收

### 6.1 平台侧治理闭环
注册留资 → 租户开通（套餐+费率+管理员+模板角色下发+应用授权）→ 内容/直播审核 → 交易（双链路）→ T+1 对账（差异处置）→ 商家确认 → 财务双人复核 → 打款 → 发票/台账 → 全局数据回流；风控贯穿提现/结算/工作台待办。

### 6.2 验收标准（路径⑤）

- **AC-⑤-01** 给定注册留资线索，当运营完成开通（套餐+费率+管理员），则租户进入试用中、管理员账号可登录商家后台、模板角色与应用按套餐授权到位。
- **AC-⑤-02** 给定待审直播，当审核员驳回并选择 C-02 与说明，则商家端编辑页展示驳回横幅与整改项。
- **AC-⑤-03** 给定已对平对账单，当商家确认，则该账期进入结算池并生成结算单（待商家确认→已确认）。
- **AC-⑤-04** 给定金额不一致差异，当结算专员执行「补差调账」，则工单转已补差、对账单重算且留处置记录。
- **AC-⑤-05** 给定结算单待财务复核，当原提交人尝试复核，则被拒（提交人≠复核人，R-OPS-T-080）。
- **AC-⑤-06** 给定「先票后款」租户无有效发票，当尝试打款，则被阻断并提示补票。
- **AC-⑤-07** 给定提现单命中「退款率超标」风控标记，当自动放行任务执行，则转人工且不批量通过。
- **AC-⑤-08** 给定租户被停用，当学员访问其 C 端店铺，则店铺下架不可浏览；该租户未完结结算继续走完（R-OPS-T-110）。
- **AC-⑤-09** 给定分账比例合计 97% 的规则，当保存，则被阻断并红字提示须=100%。
- **AC-⑤-10** 给定套餐改价，当次日生效，则存量租户按开通快照计费不受影响（R-OPS-P-010）。
