## 2. 内容

### 2.1 平台内容生产（P0）

与商家端内容三形态同构（`content-series/video/article(+edit/detail/outline)`、`content-category`），差异点：

- **定位**：平台标准内容库；生产后可下发/授权给租户（商家端呈现为「平台来源」只读内容）。
- **系列课编辑（2026-09-21 口径调整）**：内容信息（名称*45 字、分类、简介*256、富文本）+ **关联商品**（只读：列出该内容在各租户下发的镜像商品及价格/审核态）+ 分享设置；「保存并进入目录」。**原「商品信息（获取方式/价格/分组/访问密码/有效期/上架策略/店铺显示）」锚区已移除** —— 平台内容不承载价格与售卖策略。
- **目录**：章节弹窗（章节名*、视频名*、时长、视频来源*[引用不上传]、必修/**允许试看**）；已上架只读。
- **视频库**：状态含「转码中」（进度条）；来源 mp4/mov ≤2GB 或引用。
- **分享**：短链 `yibo.app/s/{id}` + 二维码。
- **规则 R-OPS-C-010**：平台内容变更后对已下发租户的同步策略（实时/次日）为 `来源:产品补全`，建议次日生效并保留租户侧上下架状态。
- **规则 R-OPS-010（2026-09-21 新增）**：平台内容与平台商品下发 shall 仅携带「**允许上架模块**」建议值（如：允许上架至首页线上课 / 精选文章）；**不得代商家决定**免费/付费、试看范围与下单方式。商家须在 `admin/mp-home.html` 为每条内容逐条完成上架配置（R-MP-070）。

## 6. 治理闭环与验收

### 6.1 平台侧治理闭环
注册留资 → 租户开通（套餐+费率+管理员+模板角色下发+应用授权）→ 内容/直播审核 → 交易（双链路）→ T+1 对账（差异处置）→ 商家确认 → 财务双人复核 → 打款 → 发票/台账 → 数据看板回流；风控贯穿提现/结算/工作台实时待处理。

### 6.2 验收标准（路径⑤）

- **AC-⑤-01** 给定注册留资线索，当运营完成开通（套餐+费率+管理员），则租户进入试用中、管理员账号可登录商家后台、模板角色与应用按套餐授权到位。
- **AC-⑤-02** 给定待审直播，当审核员驳回并选择 C-02 与说明，则商家端编辑页展示驳回横幅与整改项。
- **AC-⑤-03** 给定已对平对账单，当商家确认，则该账期进入结算池并生成结算单（待商家确认→已确认）。
- **AC-⑤-04** 给定金额不一致差异，当结算专员执行「补差调账」，则工单转已补差、对账单重算且留处置记录。
- **AC-⑤-05** 给定结算单待财务复核，当原提交人尝试复核，则被拒（提交人≠复核人，R-OPS-T-080）。
- **AC-⑤-06** 给定「先票后款」租户无有效发票，当尝试打款，则被阻断并提示补票。
- **AC-⑤-07** 给定提现单命中「退款率超标」风控标记，当自动放行任务执行，则转人工且不批量通过。
- **AC-⑤-08** 给定租户被停用，当学员访问其 C 端店铺，则店铺下架不可浏览；该租户未完结结算继续走完（R-OPS-T-110）。
- **AC-⑤-09** 给定分账比例合计 97% 的规则，当保存，则被阻断并红字提示须=100%。
- **AC-⑤-10** 给定套餐改价，当次日生效，则存量租户按开通快照计费不受影响（R-OPS-P-010）。
- **AC-⑤-11** 给定平台内容已下发租户，当下发记录展开，则仅展示「允许上架模块」建议值，**不出现免费/付费、试看范围、下单方式的代填**（R-OPS-010）。
- **AC-⑤-12** 给定商家提交的商品为 `inline` 上架位但未指定同内容成交商品，当运营审核该商品，则详情面板展示上架配置并标记异常，通过操作被阻断（R-MP-080/090）。
- **AC-⑤-13** 给定一笔由 `inline` 成交的订单，当打开订单列表与详情，则「成交商品」「上架位」「内容来源 / 结算模式」均按成交商品取数一致（R-TRD-070）。
