## 使用方法

1. 先开一次决策会，把 **§1 待决策** 逐条勾成「结论」。  
2. 再审 **§2 P0 冻结表**：只允许改「建议优先级 → 冻结优先级」列。  
3. 冻结后：原型可继续调交互；**增减 P0 能力必须走变更**。  
4. 表中「建议」是产品助手按「最短闭环」给的默认，不是已拍板结论。

**优先级定义**

| 标签 | 含义 |
|------|------|
| P0 | 本期必做，进终版验收与研发排期 |
| P1 | 原型可保留示意；不进本期上线验收 |
| P2 / 路线图 | 完整方案能力，只进路线图附录 |
| 不做 | 明确排除（含灰产、与边界冲突） |

## 5. 冻结后立即动作

1. 更新 `ToB-PRD-大纲与写作约定.md` 状态为「约定已确认」。
