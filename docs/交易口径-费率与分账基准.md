# 交易口径 · 费率与分账基准

> 版本：v1.0 ｜ 日期：2026-09-11 ｜ 状态：**唯一口径**（全站以此为准）
> 依据：《艺博教育通联云商通对接方案》、`docs/ToB-PRD-待决策与P0冻结表.md`（F4）
> 适用：商家后台「交易」、运营后台「交易与结算」、C 端支付与订单

## 一、统一费率口径（全站唯一）

| 概念 | 基准值 | 承担方 | 说明 |
|---|---|---|---|
| **入金手续费**（通联收单） | **0.30%** | 渠道成本，从交易额中扣除 | 通联方案报价 1；不参与平台/商家分账 |
| **平台服务费**（链路 B） | **0.60%** | 商家承担 | 商家自建内容；套餐/合同可覆盖，默认 0.6% |
| **平台佣金率**（链路 A） | **20%** | 平台留存 | 平台内容；可按内容/商品单独配置 |
| **提现手续费** | **1 元/笔** | 商家承担 | 通联代付 |
| **企业实名认证费** | **5 元/次** | 商家承担 | 进件企业认证（通联收取） |
| **云商通系统费** | 年流水 ≥ 5,000 万免费；否则首年 3 万 / 次年 2 万 | 平台承担 | 通联方案报价 2 |

> **已废弃口径**（历史原型中出现的数字，不再使用）：1%、2%、10%、12%、15%、5%、0.28%、0.6%（作为收单费率的用法）。
> 收敛前全站共有 6+ 个并存数字，现已统一为上表。

## 二、分账双链路

### 链路 A · 平台内容（运营后台下发）

```
用户支付 ¥100
  → 艺博入金收款主体 → 艺博存管账户
  ├─ 商家（小B 会员）：拿「佣金」= 100 × 20% = ¥20
  └─ 艺博平台：留存 ¥80
splitRule = [{ 商家会员, 20% }, { 艺博平台, 80% }]
```

**资金归属**：课程金额进艺博账户，商家只拿佣金。

### 链路 B · 商家自建内容

```
用户支付 ¥100
  → 艺博入金收款主体 → 艺博存管账户
  ├─ 商家（小B 会员）：拿「课程金额 − 服务费」= 100 − 0.6 = ¥99.40
  └─ 艺博平台：收「服务费」= 100 × 0.6% = ¥0.60
splitRule = [{ 商家会员, 99.4% }, { 艺博平台, 0.6% }]
```

**资金归属**：商家拿课程金额，平台按套餐服务费率收服务费。

### 通道对比

| 维度 | 链路 A · 平台内容 | 链路 B · 商家自建内容 |
|---|---|---|
| 内容来源 | 运营后台内容中台下发 | 商家后台创建 |
| 商家所得 | 佣金（默认 20%） | 课程金额 − 服务费（默认 0.6%） |
| 平台所得 | 留存（100% − 佣金率） | 服务费（0.6%） |
| 退款资金 | 退艺博账户资金 | 退商家账户资金（**受余额约束**） |
| 发票方向 | 商家 → 艺博（佣金） | 艺博 → 商家（服务费） |
| 权益回收 | 平台主导 | 商家主导 |
| 商家可否编辑 | 否（只读） | 是 |

### 计算公式

```
链路 A：商家佣金     = （交易额 − 退款额）× 佣金率
        平台留存     = （交易额 − 退款额）− 商家佣金

链路 B：平台服务费   = （交易额 − 退款额）× 服务费率
        商家应结算   = （交易额 − 退款额）− 平台服务费

通用：  入金手续费   = 交易额 × 0.30%（渠道成本，单列）
```

## 三、订单必备字段（冗余快照，避免历史订单被规则变更追溯）

| 字段 | 取值 | 说明 |
|---|---|---|
| `content_source` | `platform` / `self` | 内容来源，决定走哪条链路 |
| `settle_mode` | `commission` / `service_fee` | 佣金模式 / 服务费模式 |
| `commission_rate` | 百分比 | 链路 A，如 20% |
| `service_fee_rate` | 百分比 | 链路 B，如 0.6%；来源：套餐 / 租户合同 |
| `channel_fee_rate` | 百分比 | 入金手续费，如 0.30% |
| `payee_member_id` | 会员号 | 收款方（商家小B会员） |
| `platform_merchant_id` | 商户号 | 艺博入金收款主体 |
| `split_rule_snapshot` | JSON | 下单时的分账规则快照 |

---

## 四、规则优先级与生效

1. **内容来源优先**：先按 `content_source` 判定链路，同一订单只能命中一条链路。
2. **费率覆盖顺序**（链路 B）：商品/分组 > 租户合同 > 套餐 > 全局默认（0.6%）。
3. **变更生效**：规则修改仅对**生效时间之后支付**的订单生效；已支付订单按 `split_rule_snapshot` 执行。
4. **对账口径**：按订单**支付时间**入账；服务费/佣金在账期内随退款冲减。

## 五、连带约束

| 约束 | 说明 |
|---|---|
| 退款余额 | 链路的退款受「当日退货额 ≤ 当日交易额」且「≤ 原收款人账户余额」约束，不足需先充值 |
| 提现前置 | 会员须完成**提现协议签约**，未签约禁止提现 |
| 下单前置 | 会员须完成**绑定手机**，未绑定不能创建订单 |
| 提现时点 | `withdrawType`：D0 实时代付 / D0customized 每整点 / D1（次日 14:00）/ T1customized（T+1 工作日） |
