## 1. 工作台

### 1.1 模块目标
商户管理员打开后台第一屏即看到经营结果与今日必须处理的事。

### 1.2 页面与交互：`dashboard.html`（P0）

- **页面目的**：经营结果 + 实时待处理 + 待办中心聚合。
- **结构**：
  1. 经营结果 4 卡：今日新增线索 / 支付订单 / GMV / 退款率（点击跳对应列表页）。
  2. 实时待处理 4 卡：未分配线索 / 直播待提交审核 / 促到 SOP 异常 / 待处理售后（点击带筛选跳待办中心）。
  3. 待办中心：Tab（必须处理 / 运营建议）+ 类型与负责人筛选；空态「当前没有需要处理的事项」。
  4. 今日直播列表 + 快捷创建入口（创建直播/创建课程/新建线索）。
  5. 时间粒度切换：今日 / 昨日 / 7 日。
- **关键交互**：
  - 角色切换器（演示：商户管理员/助教销售/审核员/内容运营）切换视角可见模块。
  - 分配线索弹窗含「分配并创建首次跟进待办」勾选项。
  - 数据加载失败显示横幅 + 重试；「重置演示数据」仅原型用。
- **权限**：卡片与待办按数据范围过滤（销售只看本人）。

## 2. SCRM

### 2.1 模块目标
把公域流量（视频号/直播）沉淀为私域线索，通过分配、跟进、促到完成转化；侧栏结构对齐现网 SCRM（客户中心/全域获客/营销管理/内容中心/业务设置），降低 IP 迁移成本。

### 2.2 全域获客 · 视频号承接

#### `videos.html`（P0，路径③核心）
- **结构**：3 Tab —— 商品与领课（P0 验收）/ 订单（P0）/ 店铺授权（部署配置，不阻断验收）。
- **Tab1 商品与领课**：
  - 筛选：商品名 / 关联类型（平台课程·直播商品）/ 自动发短信 / 引导加微 / 状态。
  - 列：视频号商品、外部商品ID（vx_sku_*）、关联平台课/直播、领课短信模板、自动发短信、引导加微、状态（已启用/待配置）、更新时间。
  - 行操作：编辑配置 / 停用（confirm「停用后新订单不会自动发领课短信」）/ 关联。
  - **规则 R-SCRM-001**：未配置关联的商品，订单照常同步但不发领课短信、不生成领课任务（R-SCRM-007，原型编号沿用）。
- **Tab2 订单**：
  - 筛选：订单号 / 手机号 / 支付状态（已支付·已退款）/ 短信状态（已发送·失败·未发送）/ 领课状态（已领·未领）/ 加微状态（已添加·未添加·已流失）。
  - 列含三状态组；行操作：重发短信（失败单）/ 复制领课链接 / 查看线索（跳 `leads.html`）。
  - 「同步指定订单号」：输入单号手动拉取。
  - 手机号脱敏，点击展开完整号（权限+留痕，同 §用户）。
- **Tab3 店铺授权**：小店授权（小店ID*、授权密钥*）、绑定橱窗（橱窗ID*、橱窗密钥*）；授权指引折叠面板；规则：绑定橱窗后课程审核通过自动上架橱窗，未绑定需手动上架。
- **状态机（视频号订单）**：短信：待发送→已发送/失败；领课：未领课→已领课；加微：未添加→已添加/已流失。

### 2.3 客户中心

#### `leads.html` 线索池（P0，路径④核心）
- **结构**：6 Tab —— 待分配线索 / 分配规则 / 导入历史 / 渠道对接 / 数据迁移 / 三方调试。Header：导出 / 导入 / 新建线索。
- **待分配池**：
  - 筛选：姓名手机号 / 订单号 / 达人推荐人 / 线索等级（A/B/D/H）/ 阶段 / 意向 / 渠道 / 期次 / 归属人 等（「展开」收纳更多）。
  - 列：姓名、手机号（脱敏）、订单号、等级、阶段、意向、标签、归属人、归属部门、跟进时间、跟进记录数、分配时间；操作：详情/编辑/删除。
  - 批量：勾选后「批量分配(N)」；分配弹窗可选「分配并创建首次跟进待办」。
  - 工具：同步指定订单号、列展示配置、分配统计、运行记录、手工运行分配。
  - 隐私：姓名/手机号默认脱敏，点击展开（权限点：查看完整手机号，见 §9 权限）。
- **新建/编辑线索弹窗**：姓名*、手机号*（11 位校验）、线索等级、阶段、意向、渠道来源（手工新建/视频号/直播小程序/OpenAPI）、推广期次、归属人、归属部门、号码归属、性别、备注。
- **分配规则 Tab**：说明「视频号订单优先按商品对应分配规则，无规则时走通用自动分配」；规则列表空态。**裁决 Q-05**：补独立「分配规则」配置页（P0，见 2.10）。
- **导入历史**：批次编码、原文件名、类型、导入目标（学员订单）、总/成功/失败/跳过、批次状态、操作人；导入弹窗：限 xlsx/csv、必含姓名+手机号、按手机号去重、模板下载。
- **渠道对接**：三方/学员订单同步写入渠道订单表并流入线索池；需先完成权益阶段映射；列含同步渠道、金额、购买内容、商品类型、权益类型、服务老师、达人、处理状态（成功/待处理）、是否退单、留资时间；详情跳 `orders.html`。
- **数据迁移**：XXL-JOB 每 5 分钟拉取历史学员/资产订单，默认 1000 条/次，游标记录，直写正式线索不进渠道订单表。
- **三方调试**：按 userId 查询三方节点（联调工具）。
- **上下文跳转**：支持 `?action=create`（自动开新建）、`?focus=unassigned`、`?from=dashboard`；从用户详情进入无线索时显示空态+「创建跟进线索」，顶栏显示「正在查看用户：xxx」横幅。
- **状态机（线索，S-3 已冻结，总册 §9/Q-04 口径）**：
  - 主阶段：新线索 → 跟进中（子阶段：已加微 / 待到课）→ 已转化；旁路：无效 / 战败（须经审批，见 approval）；转移/无效/战败申请中为流转态。
- **去重规则（R-SCRM-020）**：手机号精确 > 订单号 > 姓名+渠道；合并策略：保留最新 / 仅标记不合并。

#### `follow-ups.html` 跟进管理（P0）
- 双层 Tab：销售组（一组~四组）× 线索卡（全部 / 我的线索 / 今日待跟进 / 逾期）。
- 筛选含线索状态枚举（跟进中/已无效/已战败/转移申请中/战败申请中/无效申请中）。
- 批量：转移负责人、调整阶段/等级（带计数）。
- 写跟进抽屉：方式（电话/企微/短信/面谈）、意向、阶段、下次跟进时间（datetime）、关联素材；底部「写跟进」入口承接线索详情。
- 转移弹窗：新组、新人、原因（组内调整/请假代管/离职移交）。
- 逾期标红；行操作含「邀请加微」「协作人」；状态类变更走审批流（`approval.html`）。

#### `group-follow.html` 企微群跟进（P0）
- 筛选：群名/群标签/群主/时间段；列：群名称、群标签（核心/转化/复购/服务）、群主、人数、本地标签、最近跟进、状态（活跃/冷启动）。
- 群详情抽屉 + 群跟进抽屉（方式：群内消息/群公告/私聊群主/群SOP；群阶段：冷启动→活跃转化→复购运营）；打标签多选弹窗（核心/转化/复购/服务/沉睡/高净值）。
- 跳转：`sop-group.html`。

#### `rules-config.html` 规则配置（P0）
- 6 Tab：意向等级 / 线索等级 / 线索阶段 / 跟进事件 / 去重规则 / 场景原因。
  - 意向等级：high 高意向 / mid 中等 / observe 观望 / no 无意向（no 停用保留编码）——**裁决 Q-03**：全端按此 4 级收敛。
  - 线索等级：A 高价值 / B 普通 / D 待培养 / H 高净值（高质量线索优先分配；高客单 VIP 优先）。
  - 线索阶段：树形（新线索→跟进中[已加微/待到课]→已转化；无效/战败），支持拖拽排序。
  - 跟进事件：phone_call/wechat_msg=人工记录；add_wechat=企微回调；attend_live=直播系统回调（绑定到阶段）。
  - 去重规则与场景原因：见线索池规则；战败原因（客户主动放弃/竞品已购）、无效原因（无法联系/非目标人群）、转移原因（组内调整/离职移交）。
- 等级弹窗：编码*、名称*、排序、状态、颜色（仅意向等级）、说明；删除 confirm。

#### `leads-dup.html` 重复线索（P0）
- 筛选含流入方式（渠道对接/手工新建/批量导入/OpenAPI）+ 命中规则；列含「拆分」依据（手机号匹配/订单号匹配/姓名+渠道）。
- 行操作：合并 / 忽略 / 拆分 / 详情；合并抽屉：选主线索 radio + 策略（保留最早/最新/手动指定）；支持批量合并/忽略。

#### P1：`approval.html` 审批管理
- 3 Tab：转移审批 / 无效审批 / 战败审批；筛选状态（待审批/已通过/已驳回）；详情抽屉含审批意见（选填）+ 通过/驳回；通过后线索状态联动 follow-ups。
- 状态机：待审批→已通过/已驳回。

#### P1：`wecom-inherit.html` 客户继承
- Tab：在职继承 / 离职继承 / 分配记录。在职=双栏转出/接收（4 维选择：按员工/线索/微信客户/客户群）；离职=自动列出离职员工资源（线索/客户/群），同类资源自动合并；确认转移按钮初始 disabled。
- 分配记录状态：已完成/处理中。

#### P1：`wecom-churn.html` 流失提醒
- Tab：全部 / 客户删除客户 / 员工删除客户 / 客户退群 / 退群设置；筛选（归属人/流失类型/原因/时间段）；操作：查看客户线索/详情。

#### `live-invite.html` 直播促到 SOP（P0，路径④核心）
- **定位**：面向私域的邀约/催到/开播提醒/直播中召回；**标准预约提醒归直播模块 live-booking，本页不做系统提醒**（职责分离，硬约定）。
- 筛选：关联直播 / 推广期次 / 来源渠道（视频号+企微/视频号/企微/短信）/ 客户阶段 / 是否加微 / 是否预约 / 是否到场 / 是否下单 / 状态（6 态）。已结束场次禁用新建（title 提示）。
- 列表列：计划名称+ID、关联直播、步骤数、目标客户、实际触达、新增预约、到课、下单、成交金额、状态、操作（详情/启动/暂停/取消/编辑）。
- **新建弹窗**：
  - 基础：计划名称*、关联直播*、推广期次、来源渠道。
  - 人群筛选：阶段 / 加微 / 预约 / 意向（高/中高）。
  - 排除条件 5 checkbox：已购买指定商品（默认勾，商品默认「本场直播关联课程(自动)」）、已退订营销、近期已触达（时间窗 3/7/14/30 天，默认 7）、已流失、黑名单。
  - 步骤表：默认 4 步（直播前邀约 24h → 预约后催到 2h → 开播前提醒[关联标准预约提醒] → 开播中未到场召回 10m）。
- **步骤编辑**：触发时机 5 类（开播前/开播后/结束后/预约成功后/关联预约管理——只读引用）+ 数值 + 单位（分/时/天）；受众=场景条件 6 预设（沿用SOP筛选/高意向未预约/已预约/已预约未进入/观看未下单/新预约）或用户分群；渠道多选（企微/短信/站内信）；执行方式=自动发送（内容类型：快捷话术/助销素材/直播卡片）或助教人工任务（执行要求*、负责人规则：线索负责人/直播负责人/指定助教；截止 2/6/12/24/48h）。
- **启动前校验（R-SCRM-030）**：硬阻断=直播已结束/未过审/未上架/人群为空/无步骤/触发时间全过期（附「去处理」跳转）；警告=触发已过将跳过；确认弹窗摘要含预估人数、排除明细、逐步骤内容预览。
- **SOP 状态机**：draft→scheduled→running→paused/completed/cancelled；步骤状态：draft/linked_booking/pending/running/completed；约束「自动步骤状态由系统执行结果产生，编辑时不可设为执行中/已完成」。
- 详情抽屉：转化漏斗 5 级（目标→触达→预约→到场→支付）+ 到课率/触达→预约率/到场→下单率/单次触达成本；人工步骤可手动「完成」。

#### `quick-tasks.html` 快捷任务（P0）

### 2.8 SCRM 验收标准（路径③④相关）

- **AC-③-01** 给定已启用配置的视频号商品，当买家支付，则系统生成订单记录并在短信渠道发送领课短信。
- **AC-③-02** 给定短信发送失败，当运营点「重发短信」，则记录新一条发送记录且状态刷新。
- **AC-③-03** 给定未配置关联的商品订单，当订单同步，则不发短信、不出领课任务（R-SCRM-007）。
- **AC-④-01** 给定新线索入池且命中商品×期次分配规则，当规则执行，则线索归属按规则人/组，并产生分配时间。
- **AC-④-02** 给定重复手机号线索，当流入，则按去重规则命中并进入重复线索处理列表。
- **AC-④-03** 给定 SOP 关联直播为「审核中」，当尝试启动，则被硬阻断并提示原因（R-SCRM-030）。
- **AC-④-04** 给定促到 SOP 运行中且步骤为自动发送，当触发时间到达，则按渠道发送并回写触达数。
- **AC-④-05** 给定助教人工步骤，当到期未完成，则在待办与逾期标识中可见。
- **AC-④-06** 给定两条重复线索合并，当选择主线索与策略，则非主线索标记合并来源且跟进记录归并。
- **AC-④-07** 给定销售提交战败申请，当审批通过，则线索阶段变更为已战败并记录原因。

## 6. 交易

### 6.1 模块目标

### 6.2 费率口径基准（R-TRD-000，全端唯一）

| 项 | 值 | 说明 |
|---|---|---|
| 入金手续费 | 0.3% | 通联收取，按笔，退款返还 |
| 链路 A（平台内容） | 商家佣金 20%，平台留存 80% | 平台内容订单 |
| 链路 B（自建内容） | 平台服务费 0.6%，商家应结 99.4% | 自建内容订单 |
| 提现费 | 1 元/笔；实名认证 5 元/次 | 通联报价 |
| 废弃口径 | 1% / 2% / 10% / 12% / 15% / 5% / 0.28% | 不再出现（Q-01） |

**分账算法（R-TRD-001）**：`base = 实付 − 已退款`；链路 A 平台所得 = base×20%，链路 B 平台所得 = base×0.6%；分账金额四舍五入到分，商家=差额；channelFee = 实付×0.3%；已退款订单分账状态=「已冲正（清分回退）」，否则「待分账 T+1 自动分账」。历史订单按规则快照结算；改规则仅对修改后支付的订单生效。

## 8. 经营分析

### 8.1 模块目标
以「私域运营漏斗 + 交易结果」双视角量化获客→转化，支撑期次复盘。

### 8.2 看板（P0）

| 看板 | 核心内容与口径 |
|---|---|
| `board-overview.html` 总览 | 主漏斗：私域池→已加微→有到场→可归因支付（端到端转化率）；核心 KPI（私域池/加微率/到场/支付/GMV/退款，环比+目标）；漏斗步可下钻（渠道/期次/员工/直播）并「应用为全局筛选」；经营瓶颈+待办风险卡；5 专题入口 |
| `board-term-review.html` 期次复盘 | **「全部期次」不能复盘**（强制选具体期次）；期次 hero（负责人/周期/转化截止/剩余天数/关联直播/渠道数）；端到端漏斗（入池→分配→加微→跟进→到场→支付）；趋势 8 指标；渠道质量贡献、私域承接、关联直播、转化分区 |
| `board-acquire.html` 获客 | 渠道质量表（入池/有效率/加微率/到场率/支付率/归因 GMV/vs 整体 pp/环比/主要流失）；**视频号获客首单为辅口径不进后链路**；辅漏斗：首单→流入线索→领课；短信失败重发入口；**暂无投放成本，不展示 CAC/ROI** |
| `board-private.html` 私域转化 | Tab1 团队执行：待分配积压（含超时）/响应及时率/加微率/无跟进数；员工执行表（承接量/及时率/加微/覆盖率/超时/未跟进/支付/vs 团队）；Tab2 用户运营：跟进覆盖率、阶段运营表（停留/超时未流转/可再触达）、高意向未支付。（原 board-follow/board-handoff 并入本页双 Tab，Q-12） |
| `board-live.html` 直播 | 全部场次/平均到课率/**促到到课差（标注「相关非因果」）**；已结束场次表（到场/支付率排序、与平均差距、未执行 SOP、风险）；抽屉复盘迷你漏斗（目标→邀约→推送成功→到场→有效观看→支付） |
| `board-convert.html` 交易 | **双分区固定**：A 可归因交易（漏斗关联；支付/订单/GMV/客单/到课成交 vs 未到课/退款；受全局筛选）+ 归因覆盖率、未归因订单「计入全量不混入可归因」；B 成交结果（支付事件口径，全量 GMV/退款率/商品排行；不受获客渠道筛选） |

### 8.3 指标口径原则（R-BI-001）

- 归因口径与结果口径分离：可归因交易只统计漏斗关联支付；成交结果区为全量支付事件。
- 看板数据受全局筛选（渠道/期次/时间）联动；期次复盘必须锚定单期次。
