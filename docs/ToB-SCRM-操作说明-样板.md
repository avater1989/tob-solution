## 一、系统概述

艺博 To-B SCRM 帮商户把视频号买课的人接到私域里：先把商品配上领课短信，订单进来后自动（或补发）短信让家长领课；线索进池、分给助教，日常写跟进、直播前用短信促到；同一个人进来两次就合并，避免两个人同时跟。

**本册范围（走通路必会的五页）**

| 章 | 功能 | 日常干什么 |
|----|------|------------|
| 二 | 视频号 | 关联商品、配领课短信；看订单、重发短信、复制领课链接 |
| 三 | 线索池 | 看待分配、批量分人、配分配规则、手工新建/导入 |
| 四 | 跟进管理 | 今日待跟进、写跟进、邀请加微、调阶段/转人 |
| 五 | 直播促到 SOP | 建促到计划、配短信步骤、启动、看触达结果 |
| 六 | 重复线索 | 选主线索合并，避免重复分配 |

线索日常怎么走：新建 → 已分配 → 跟进中 → 已转化 / 已流失。加微、领课是旁边两列状态，可以同时「跟进中 + 已领课 + 未加微」，不要把加微/领课当成主状态。

**本册不写细（后置）**：欢迎语、获客链接、渠道活码、客户群发、助销素材、快捷话术、快捷任务等。菜单里可能看得到，但不挡本册最短闭环，后续单独出说明。

视频号里的「店铺授权」Tab 是部署配置，非本说明主路径，下文只带一句。

## 二、视频号

视频号把「小店卖出去的课」接到咱们平台：一边配商品和领课短信，一边看订单有没有发出去、家长领没领、加没加微。

### 2.1、商品与领课

▪ 功能描述：视频号上新了课或直播商品，要先在这里关联到平台课/直播，并配好领课短信。配好以后，家长一付款，系统就能自动发短信让他领课、顺手引导加微；没配模板的商品，订单还能进来，只是不会自动发短信。

▪ pc管理端导航路径：SCRM → 全域获客 → 视频号 → 商品与领课

▪ 数据管理/初始化：商户管理员负责关联商品、配短信模板、启停；平台课/直播要先在内容/直播侧上好。店铺授权由平台部署同步，本页不依赖授权 Tab 才能操作。

▪ 使用角色：商户管理员（配置）；助教/销售一般只读，不改全局商品配置。

▪ 操作：

  • 进入 SCRM → 全域获客 → 视频号，默认落在【商品与领课】。

  • 点击【+ 关联商品】（或行里状态是「待配置」时点【关联】），弹出「关联商品 / 领课配置」：选视频号商品、关联类型（平台课程 / 直播商品）、对应平台课或直播；填写领课短信模板（里面要带领课链接占位，如 `{{claim_link}}`）；选要不要【自动发短信】、要不要【引导加微】；点【保存配置】。保存成功后列表出现「已启用」。

  • 已配好的行，可点【编辑配置】改模板或开关，点【停用】后新订单不再自动发短信。可用筛选（商品名、关联类型、自动发短信、引导加微、状态）后点【查询】。

![视频号-商品与领课](manual-shots/01-videos-goods.png)

> 图内 ① 商品与领课 Tab　②【+ 关联商品】　③ 商品表格（行内【编辑配置】【停用】）

> 「店铺授权」Tab 标了「部署配置」，授权微信小店、绑定橱窗由平台部署处理，**非本说明主路径**，一线不需要在这里完成才能配商品、看订单。

### 2.2、订单

▪ 功能描述：视频号付过款的订单都在这里。用来核对短信发没发出去、家长领没领课、加没加微；短信失败可以重发，人肉触达可以复制领课链接，需要跟进的点「线索」跳到线索池。

▪ pc管理端导航路径：SCRM → 全域获客 → 视频号 → 订单

▪ 数据管理/初始化：订单由视频号侧同步进来，商户管理员盯短信/领课异常；助教可从订单跳到线索继续跟。手机号默认脱敏，有权限再点开看完整号码。

▪ 使用角色：商户管理员、助教/销售。

▪ 操作：

  • 进入 SCRM → 全域获客 → 视频号，点 Tab【订单】。

  • 列表能看到：订单号、脱敏手机、商品、支付、短信状态、领课、加微、下单时间。按订单号/手机号/支付/短信/领课/加微筛选后点【查询】。缺某笔时可用【同步指定订单号】或右上角【同步订单】补同步。

  • 短信是「发送失败」或「未发送」时，点行内【重发短信】，系统再发一次（仍失败会留痕）。需要打电话/企微人肉触达时，点【复制领课链接】，链接进剪贴板。要点开这条人的跟进，点【线索】跳到线索池。

![视频号-订单](manual-shots/01b-videos-orders.png)

> 图内 ① 订单 Tab　② 行操作【重发短信】　③ 订单表

  • 未配领课模板的商品，订单仍会进来，只是不会自动发短信——回到【商品与领课】把模板配上。领课链接过期时，复制/打开会提示过期，后台可再发一条新链。家长重复点领课，前台显示已领取即可，后台仍记已领。

## 三、线索池

▪ 功能描述：所有还没分到具体助教、以及刚从视频号/导入进来的线索，都先在线索池里。管理员在这里看待分配、按规则自动分或勾选后批量分人，也可以手工新建、批量导入。分出去的人会出现在「跟进管理」里，助教才能开始跟。

▪ pc管理端导航路径：SCRM → 客户中心 → 线索池 → 待分配线索

▪ 数据管理/初始化：视频号订单、批量导入、手工新建都会进池；商户管理员配【分配规则】（渠道 × 商品 × 期次 → 成员轮询或人均上限）并启用。渠道对接、数据迁移、三方调试给部署/对接同事用，日常以待分配 + 分配规则为主。

▪ 使用角色：商户管理员（分配、建规则、导入）；助教日常在跟进管理看名下线索，线索池以管理员操作为主。

▪ 操作：

  • 进入 SCRM → 客户中心 → 线索池，默认在 Tab【待分配线索】。

  • 用姓名/手机号、订单号、达人、线索等级、线索阶段、意向等级筛选，点【查询】（【展开】可开更多条件）。手机号、姓名默认脱敏，点【点击查看完整手机号】/【点击查看完整姓名】按权限揭开。

  • 勾选多条（没勾选时【批量分配】是灰的），点【批量分配】，弹出「分配线索」，选归属人、归属部门，点【确认分配】。分成功后线索进入「已分配」，助教就能在跟进管理里看到。单条也可点【详情】【编辑】【删除】。

![线索池-待分配](manual-shots/02-leads.png)

> 图内 ① Tab 区（待分配线索 / 分配规则 / …）　② 筛选条　③ 列表与分配（【批量分配】、行内【详情】【编辑】【删除】）

  • 切到 Tab【分配规则】，点【新建分配规则】，按渠道 × 商品 × 期次指定成员（轮询或人均上限），保存后【启用】。没命中规则或一时没人可分的，线索继续留在待分配，再手工批量分即可。

  • 右上角【新建线索】填姓名、11 位手机号等后【保存】；【导入线索】先【下载模板】，上传 xlsx/csv（必须有姓名、手机号，按手机号去重）后点【开始导入】。导入结果在 Tab【导入历史】看成功/失败。需要时【导出线索】。

  • 无线索时，空表会提示先去配视频号商品或导入线索。视频号同步若缺手机号，线索仍入库，标数据质量问题，不挡同步。

## 四、跟进管理

▪ 功能描述：助教每天干活的主页面。分到自己名下的线索都在这：看今日待跟进和逾期、写跟进、改意向、邀请加微、把阶段往前推。管理员可抽查全部、转移负责人、调整阶段/等级。写过跟进后，线索会从「已分配」走到「跟进中」；最后变成「已转化」或「已流失」。加微、领课是旁边两列，跟主状态分开看。

▪ pc管理端导航路径：SCRM → 客户中心 → 跟进管理

▪ 数据管理/初始化：线索由线索池分配后进入本页；商户管理员可批量转移、调整阶段/等级。分组按一组 / 二组 / 三组 / 四组（商户自己的组，不是固定业务线名）。

▪ 使用角色：助教/销售（写跟进、邀请加微）；商户管理员（抽查、转人、调阶段）。

▪ 操作：

  • 进入 SCRM → 客户中心 → 跟进管理。

  • 顶部先选组：【全部】【一组】【二组】【三组】【四组】；下面再切【全部】【我的线索】【今日待跟进】【逾期】。日常建议先开【今日待跟进】，把逾期清掉。

  • 点行内【跟进】（或详情里【写跟进】），填写跟进方式（电话/企微/短信/面谈）、意向等级、线索阶段、跟进内容、下次跟进时间，需要时关联素材，点【保存】。列表「上次跟进 / 下次跟进」会更新。

  • 同一行还可【详情】看基础信息和跟进时间线，【邀请加微】生成加微邀请，【编辑】改姓名/等级/归属组（一组～四组）等。勾选多条后可用【转移负责人】（选新归属组、新归属人、原因，点【确认转移】）、【调整阶段/等级】。无效/战败在详情更多操作里选原因后【提交】即可（本期直接改，不必走审批）。

![跟进管理-今日待跟进](manual-shots/03-follow-ups.png)

> 图内 ① 分组 Tab（全部 · 一组 / 二组 / 三组 / 四组；二级：全部 / 我的线索 / 今日待跟进 / 逾期）　② 待跟进列表　③ 行操作【详情】【跟进】【邀请加微】【编辑】

  • 今日没有待跟进时，空态会提示可切回全部/我的线索。跟进内容没填点不了保存。没有权限改别人的线索时，操作会隐藏或提示无权限。标签若用户模块还没开，这里只展示已有标签，不能新增。

## 五、直播促到 SOP

▪ 功能描述：下场直播开播前，把还没到课、还没加微的人用短信按点触达（开播前催到、预约后催到、直播中召回）。管理员建计划、圈人、配步骤并启动；助教看触达结果和未到课名单，再回到跟进里私聊。标准的「开播前提醒 / 改期 / 取消」走预约管理，本页不做系统预约提醒，避免配两遍。

▪ pc管理端导航路径：SCRM → 营销管理 → 直播促到 SOP

▪ 数据管理/初始化：商户管理员建计划、配短信步骤；关联直播须已审核通过。短信通道由平台部署对接；外呼本期不用。

▪ 使用角色：商户管理员（建计划、启动）；助教/销售（看结果、回跟进）。

▪ 操作：

  • 进入 SCRM → 营销管理 → 直播促到 SOP。可按关联直播、推广期次、来源渠道、客户阶段、是否加微/预约/到场/下单、状态筛选后【查询】。

  • 点击【+ 新建直播促到SOP】，填计划名称、关联直播（必填）、推广期次、来源渠道；在人群筛选里圈人（例如未加微、未预约、未到场）；排除条件默认可勾已购买 / 已退订 / 近期已触达，避免反复骚扰。

  • 在「促到步骤」点【+ 添加步骤】：填步骤名称、触发时机（如开播前 1 小时）、受众、渠道（本期以短信为主）、目标、是否自动执行，点【确定】。步骤配齐后点【保存 SOP】。

  • 列表里点【启动】，到点会按步骤发短信（草稿/已结束场次不能启动，只能看）。执行中可【暂停】。点进详情能看转化漏斗、成功/失败数；未到课名单可跳回跟进继续私聊。

![直播促到SOP-列表](manual-shots/04-live-invite.png)

> 图内 ① 计划列表　②【+ 新建直播促到SOP】　③ 表头「步骤数」（创建弹窗里配短信步骤）

  • 还没有计划时，空态提示点右上角新建。没选直播或步骤不完整会拦保存。已结束场次不能新建/启动，仅可查看。短信失败会记在结果里，可按通道规则再试。

## 六、重复线索

▪ 功能描述：同一手机号（或命中去重规则）从视频号、手工新建、批量导入各进一次时，这里会成组出现。管理员选出要留的主线索点合并，跟进记录挂到主线索上，另一条归档不再分配，避免两个人同时跟、数据对不齐。

▪ pc管理端导航路径：SCRM → 客户中心 → 重复线索

▪ 数据管理/初始化：系统按去重规则自动聚组；商户管理员确认合并或忽略误报，必要时点【去重规则】微调识别规则。助教发现重复只提报，一般不自己合。

▪ 使用角色：商户管理员（合并/忽略）；助教/销售（发现后提报）。

▪ 操作：

  • 进入 SCRM → 客户中心 → 重复线索。按姓名、手机号、流入方式、命中规则等筛选，点【查询】。

  • 点行内【合并】（或勾选后点顶部【合并】），右侧打开「合并线索」抽屉：用单选选出要保留的**主线索**，选合并策略（保留最早 / 保留最新 / 手动指定），点【确认合并】。没选主线索时确认按钮不可用。合并后从线索归档，不能再被分出去；跟进记录挂到主线索。冲突字段以主线索为准，合完可再【编辑】。

![重复线索-合并](manual-shots/05-leads-dup.png)

> 图内 ① 重复列表　②【确认合并】　③ 保留线索选择（主线索单选）

  • 误报可点【忽略】（或【批量忽略】）。不是同一人、只是被规则误判在一组，可点【拆分】填原因后【确认拆分】，这条会独立成新线索。右上角【去重规则】可调识别规则；【详情】看整组。无权限时合并入口会隐藏。

  • 没有命中重复规则时，空态显示「暂无命中重复规则的线索」。
