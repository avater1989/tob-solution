## 1. 整体导航与店铺隔离

### 1.1 导航结构
- 底部 Tabbar 3 个：**首页 / 直播 / 我的**；独立页：课程详情、直播间、领课页、学习页、支付结果。
- 金刚位固定 4 格：直播课 / 精品课 / 领课 / 我的（「领课」受商家端 mp-claim 开关控制显隐）。

### 1.2 店铺隔离规则（裁决 Q-06 补全设计）

| 规则 | 内容 |
|---|---|
| R-MP-010 | **带参进店**：所有入口（直播预约卡、分享短链、领课短信链接、二维码）携带 `?shop={tenant_id}`；进入后店铺上下文写入会话，后续页面沿用 |
| R-MP-020 | 无 shop 参数进入时，默认展示「选择店铺」引导页（`来源:产品补全`，原型未承载）；不允许无店铺上下文浏览商品 |
| R-MP-030 | 店铺切换：我的页提供「切换店铺」入口；切换后购物/权益上下文按店铺隔离 |
| R-MP-040 | 跨店数据不可见：我的课程、订单、领课权益均按 (user, tenant) 隔离 |

### 1.3 管理端配置透出关系

| 商家端配置 | C 端透出 |
|---|---|
| mp-home Banner/金刚位/分类/楼层 | 首页结构 |
| content 商品信息（获取方式/试看/有效期） | 课程详情「商户配置」行与锁节行为 |
| mp-claim 开关与批次 | 领课入口与兑换流程 |
| mp-live 互动/敏感词/预约提醒/回放策略 | 直播间聊天、预约提醒、回放可见性 |
| live-edit 观看资格 | 直播间准入门禁 |

## 2. 页面与交互（8 页全 P0）

### 2.1 首页 `home.html`

- **页面目的**：店铺门面 + 内容分发入口。
- **结构**：搜索框 → Hero 直播横幅（进行中直播优先）→ 四宫格金刚位 → 分类 chips → 本周必看横滑（≤6）→ 精选课程列表。
- **交互**：搜索框（关键词搜课程/直播，`来源:产品补全`：原型未实现逻辑，需求保留）；chips 按分类标签筛选（mp-home 分类标签配置）；Hero「立即预约」→ 直播详情/直播间。
- **数据来源**：全部来自商家端 mp-home 装修与内容池；无配置楼层则隐藏对应区块。
- **空态**：无 Banner 时以默认店铺图兜底；无直播时隐藏 Hero。

### 2.2 直播列表 `lives.html`

- **结构**：三 Tab —— 进行中 / 预告 / 回放；状态卡列表。
- **状态覆盖（10 态，与直播间渲染一一对应）**：live 有资格 / live 无资格 / upcoming / booked（已预约提醒未开）/ replay / ended_pending（回放生成中）/ ended_none（无回放）/ replay_off（回放关闭）/ replay_expired / rescheduled / cancelled。
- **交互**：预约（upcoming）→ 开启开播提醒；获取资格（live 无资格）→ 门票购买；进入直播间（有资格）；回放点击进入回放视图。
- **预约状态机**：未预约→已预约（可取消）；开播前按 mp-live 提醒策略推送。

### 2.3 直播间 `live-room.html`

- **结构**：深色封面+状态角标 → 面板/播放器 + 弹幕区 + 商品挂载浮层（goods-sheet）+ 评论输入。
- **准入门禁（R-MP-050）**：按 live-edit 观看资格校验（免费/持有效门票/持关联课程有效权益/密码/指定名单）；无资格渲染 `renderLiveGate()`：「购买本场资格或持有关联课程有效权益」→ 门票购买弹层。
- **门票购买**：`openBuyNotice({catalogId:"ticket", from:"ticket", returnUrl:"live-room..."})` → 支付成功 → 回直播间且获得本场资格（**权益按「商品+场次」隔离，Q-10**）。
- **挂载课购买**：商品浮层点击 → 购买须知 → 支付（from=live）→ pay-result → 返回直播间或去学习。
- **互动**：评论（按 mp-live 聊天范围与敏感词过滤）；回放视图：假进度条播放，**不展示实时聊天与在线人数**。
- **异常**：rescheduled 显示改期卡片；cancelled 显示取消说明；结束且无回放显示 ended_none。

### 2.4 课程详情 `course.html`

- **结构**：封面（试看角标）→ 价格面板 → 讲师卡 → 「你会学到」→ 目录。
- **三态**：未购（价格+收藏+立即购买）/ 已购（owned-tip 绿条+继续学习）/ 试看中。
- **目录渲染**：已购（✓/学习中高亮/时长，可点进学习页）；未购试看节（「可试看」标签→学习页 trial）；未购锁节（点击→购买引导弹层，fromLesson=该节号，购买后 return 到对应节）。
- **商户配置透出**：获取方式 / 有效期 / 试看策略一行展示。
- **收藏**：我的-收藏列表可查（`来源:产品补全`：收藏数据结构）。

### 2.5 学习页 `learn.html`

- **结构**：试看横幅 → 播放器（进度条）→ 目录+进度 → 操作区（标记完成/立即购买/返回）。
- **权益门禁（R-MP-060）**：未购且非试看节 → redirect `course.html?needBuy=1`（再弹购买）；试看按 mp-settings 策略（前 N 分钟/整节）。
- **试看结束**：`openTrialEndPrompt`（第 1 节整节可试看 / 第 2-8 节需购买）→ 继续试看或立即购买。
- **进度**：标记完成 → toast「进度已记录，下次继续」；目录 ✓/学习中标记；跨端续学（小程序/后续端进度同步，`来源:产品补全`）。
- **返回键**：试看→课程详情；已购→我的。

### 2.6 领课页 `claim.html`（路径③ C 端落点）

- **入口**：视频号订单领课短信链接（带订单号 + shop 参数）。
- **结构**：封面卡（订单号 + 课程信息）→ 领取须知 → 按钮区。
- **流程**：立即领课 → 购买须知弹层（权益类型=试听权益/包含=体验课试听内容/有效期=领取后 30 天/客服售后）→ 确认领取 → 权益发放（trialClaim）→ 成功块三出口（去学习[第 1 节]/看直播/我的）。
- **引导加微**：成功块「添加企微老师」（mp-claim 配置的老师与文案）；企微唤起失败仅提示不阻断。
- **裁决 Q-09**：增加**兑换码输入**：mine-领课兑换 与本页支持输入兑换码 → 校验（批次有效期内/未超限兑/未被使用/店铺匹配）→ 同一权益发放链路。
- **异常**：链接过期（30 天外）→ 失效页 + 引导购买；重复领取 → 「已领取，去学习」。

### 2.7 我的 `mine.html`

- **结构**：头部（昵称/手机号脱敏/已学天数）→ 三格统计（课程数/预约直播数/学习进度）→ 菜单（我的课程/我的直播/领课兑换/订单/收货地址[无实物，不做]/帮助/切换店铺[Q-06]）→ 我的课程卡 → 我的直播卡。
- **交互**：继续学习 → learn（lesson 定位）；订单 → 订单列表（C 端简版，`来源:产品补全`：原型跳商家端示意，需求为 C 端自有订单列表）；领课兑换 → claim 兑换码模式；直播卡显示「已预约提醒」。

### 2.8 支付结果 `pay-result.html`

- **聚合页，按 from 分流**：

| from | 成功后主操作 | 次操作 |
|---|---|---|
| course | 去学习（lesson 定位） | 返回课程 |
| live | 去学习（挂载课） | 返回直播间 |
| ticket | 进入直播间（获得本场资格） | 返回直播列表 |
| claim | 领取成功 → 去学习 | 我的 |

- **四态演示**：成功 / 取消 / 失败 / 待确认（待确认=支付渠道异步，权益未开通，提供「刷新结果」）。
- **权益明细卡**：展示商品、权益类型、有效期；含「备付金待分账」资金示意（仅供内部评审，C 端正式版**不展示分账信息**，`来源:产品补全` 裁决）。
- **失败/取消**：返回原位置 + 重试 + 保留购买入口。

## 3. 三条消费闭环（验收真源）

### 3.1 闭环① 看课购买学习
首页/金刚位 → 课程详情 → 试看第 1 节 → 试看结束弹层 → 立即购买 → 支付成功（pay-result from=course）→ 学习页第 2 节 → 标记完成 → 进度留存。

### 3.2 闭环② 直播预约观看购买
首页 Hero/直播列表 → 预约（开播提醒）→ 开播进入直播间 → 无资格买门票（pay-result from=ticket → 回直播间）→ 直播间挂载课购买（from=live）→ 结束后回放（按回放策略可见）。

### 3.3 闭环③ 领课兑换加微学习
视频号订单 → 领课短信 → 领课页 → 确认领取（30 天试听权益）→ 引导加企微 → 去学习/看直播；或 我的-领课兑换 → 输入兑换码（Q-09）→ 同链路。

### 3.4 验收标准

- **AC-C-01** 给定带 `?shop=` 参数的分享链接，当用户首次进入，则店铺上下文建立且后续浏览不出该店商品（R-MP-010）。
- **AC-C-02** 给定无资格直播间，当用户点击播放区，则展示门票购买弹层；支付成功回直播间并可观看。
- **AC-C-03** 给定门票为场次 A 的权益，当用户进入场次 B 直播间，则仍判定无资格（Q-10 场次隔离）。
- **AC-C-04** 给定试看策略「每节前 3 分钟」，当试看计时结束，则弹试看结束弹层且后续节锁节。
- **AC-C-05** 给定有效兑换码，当在领课页输入并确认，则发放对应批次课程的试听权益且记录批次与来源。
- **AC-C-06** 给定同一兑换码已被使用，当再次输入，则提示无效并展示已占用信息。
- **AC-C-07** 给定支付渠道返回「处理中」，当用户停留在 pay-result，则展示待确认态且可刷新结果。
- **AC-C-08** 给定回放策略「仅预约学员」，当未预约用户打开已结束直播，则不可看回放并引导预约下场。

## 4. 入口页（非 C 端页面，归商家端链路）

- `login.html` 商家后台登录：账号/密码（演示任意非空）；忘记密码提示；跳 register。
- `register.html` 商家注册留资：手机号*（11 位）、短信验证码*（6 位+60s）、姓名*、公司/机构名称、角色（创始人/市场增长/销售/运营内容/其他）、主营业务/需求描述、协议勾选*。提交后**进入平台 SCRM 线索池**，商务顾问 1 个工作日内跟进，运营后台手工开通租户（总册路径⑤起点；非自助开通）。
- `index.html` 原型导航页（非产品页面，评审用）。
