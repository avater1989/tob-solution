## 1. 背景与目标

### 1.1 战略背景

艺博从 B2C 家庭教育服务升级为 **B2B2C 行业赋能平台**：将技术、内容、获客方法论打包输出给家庭教育机构与从业者（IP）。战略细节见概念设计文档；**本期不以概念设计七大板块全家桶为研发范围**。

### 1.2 本期核心命题

**如何让几个 IP 快速上线并可用。**

以试点商户能完成最短经营闭环为目标：

**开通租户 → 上架内容/开播 → 获客承接 → 私域转化 → 交易与结算**

### 1.3 目标用户与典型客户

| 侧 | 对象 | 说明 |
|----|------|------|
| B 端 | 家庭教育机构 / IP（商户/租户） | 使用商家管理端经营：SCRM、直播、内容、小程序、交易、用户、看板 |
| B 端 | 平台运营 / 审核 / 财务 | 使用运营后台：租户与套餐、内容审核、交易与结算、全局数据 |
| C 端 | 家长 / 学员 | 使用独立 To-B 小程序看课、进直播、购买、领课、学习 |

> 首批试点 IP 名单与上线窗口见开放问题 **Q-08**（未补齐则「快速上线」无法业务验收）。本文不杜撰 IP 名称或 OKR 数字。

### 1.4 成功标准

**业务指标（试点期）**

| 指标 | 口径 | 目标 |
|---|---|---|
| 试点 IP 上线数 | 完成租户开通 + 首场直播/首个上架课程 | 按业务名单（Q-08） |
| 端到端转化 | 私域池 → 加微 → 到场 → 可归因支付 | 对齐原型总览漏斗口径（示例 21%，目标值评审定） |
| 平台费率收入 | 佣金 20%（链路 A）+ 服务费 0.6%（链路 B），退款冲减 | 覆盖通联成本（入金 0.3% 等） |

**评审/验收标准**：§5 五条主路径的 AC 用例全部通过；三端分册 P0 验收标准通过；15 条裁决项评审关闭。

## 2. 术语与假设

### 2.1 术语表

| 术语 | 定义 |
|---|---|
| 租户/商户 | 一家入驻机构，独立数据域；商家后台 + C 端店铺的唯一归属 |
| 推广期次 | 招生/推广经营周期（名称+起止+负责人+6 项目标），生命周期 upcoming→active→ended |
| 领课 | 视频号订单买家经短信链接兑换试听权益的动作 |
| 促到 | 直播前/中对未到场用户的召回触达（SOP），区别于标准预约提醒 |
| 链路 A / 链路 B | 平台内容订单（商家得佣金 20%）/ 商家自建内容订单（平台收服务费 0.6%） |
| 进件 | 通联云商通会员开通（memberType 企业=2/个人=3） |
| 提现签约 | 会员-平台-通联三方电子协议（ContractNo），未签约禁止提现 |
| 备付金/弱存管 | 通联+艺博+招行三方存管；入金入平台中间账户集，D+1 结算 |
| 双人复核 | 结算打款需第二人复核（提交人≠复核人） |

### 2.2 多租户与数据隔离假设

- C 端带参进店 `?shop={tenant_id}`（C-06 补全设计），店铺上下文贯穿会话；跨店数据不可见。
- 全局订单/测评结果等平台视角页面只读跨租户。

### 2.3 资质与合规假设（依赖状态）

| 依赖 | 状态 |
|---|---|
| 通联云商通开户、入网费率（入金 0.3%、提现 1 元/笔、认证 5 元/次） | 依赖项（已报价，S7） |
| 企微服务商身份、视频号小店授权 | 依赖项 |
| EDI / 网文许可证 | 未具备（线上课程售卖平台资质，Q-07） |

### 2.4 系统边界

大于众学 / 定制化中心（完整版）/ 客户中心（现网）不在本期；SCRM 现网结构对齐但独立实现。

### 3.1 角色清单

| 端 | 角色 | 职责要点 |
|---|---|---|
| 商家后台 | 商户管理员 | 全模块；敏感操作授权 |
| 商家后台 | 助教/销售 | 线索跟进、促到执行、群运营 |
| 商家后台 | 内容运营 | 内容生产与上架、店铺装修 |
| 商家后台 | 财务 | 订单/退款审核、结算确认、提现 |
| 商家后台 | 主播/助播（直播角色） | 中控台、大屏 |
| 商家后台 | 审核员（内部协审占位） | 内容自查（非平台审核） |
| 运营后台 | 超级管理员（内置唯一） | 全部；不可改 |
| 运营后台 | 租户管理员 / 审核专员 / 结算专员 / 数据专员 / 值班运营 / 只读访客 | 按资源树授权 |
| C 端 | 家长/学员 | 消费与学习 |

### 3.2 端 × 角色矩阵与权限原则

- 登录：商家后台与运营后台独立账号体系；C 端微信授权。
- 数据范围 4 档：本人 / 本人及下级 / 本部门 / 全部（商家端）；全部 / 指定租户 / 本人（运营端）。
- 敏感操作（须权限点 + 留痕 + 二次确认）：手机号解密（原因枚举必填）、退款审核、结算确认、批量导出（完整手机号需 canDecryptPhone + 原因）、成员管理、补开已回收权益（管理员级）。
- 内置角色不可删除；角色删除须先移除成员；模板角色变更仅影响新开通租户。
- 细矩阵见 `ToB-PRD-90-附录.md` §2。

## 5. 端到端主路径（验收真源）

> 终版以主路径验收，不以菜单穷举验收。每条路径五段：触发 → 关键步骤 → 系统结果 → 异常分支 → 验收编号。
> Given/When/Then 全文在对应分册；此处为路径级 AC。

### 5.1 路径① 内容售卖（商家端 + C 端）

- **触发**：商家创建系列课/视频/图文（内容来源=自建）。
- **关键步骤**：编辑三锚区（内容信息/商品信息/分享设置）→ 配置目录（试看/必修）→ 保存并上架（提交内容审核队列）→ 运营后台审核通过 → C 端可见 → 学员试看 → 立即购买 → 支付成功（权益自动开通）→ 学习页消费。
- **系统结果**：订单（链路 B，服务费 0.6%）+ 权益记录 + 学习进度。
- **异常分支**：审核驳回（理由必填→商家改稿重提）；权益开通失败（可重试/手动开通）；退款（按退款规则，权益回收联动）。
- **验收**：AC-①-01~06（分册 §内容/§交易）。

### 5.2 路径② 直播转化（商家端 + C 端）

- **触发**：商家创建直播。
- **关键步骤**：live-edit（观看资格四选一：免费/付费/密码/指定用户；挂载商品；场景预设）→ 提交平台审核 → 通过 → 上架（立即/定时）→ 预约自动进 live-booking → 开播预检 → 中控台开播（媒体源/互动/商品讲解/营销）→ C 端预约→提醒→进直播间（门票拦截→购票→回直播间）→ 挂载课购买 → 结束直播 → 回放生成与上架。
- **系统结果**：直播三状态正确流转；订单（门票/课程）+ 权益；预约/到场/成交数据进看板。
- **异常分支**：驳回（整改项定位）；审核中只读可撤回；未开播/已结束门禁；回放生成失败；非 living 不可进中控台。
- **验收**：AC-②-01~08。

### 5.3 路径③ 视频号获客承接（商家端 + C 端）

- **触发**：视频号小店订单产生。
- **关键步骤**：视频号商品关联配置（平台课/直播 + 短信模板 + 自动发短信 + 引导加微）→ 订单同步（订单 Tab）→ 自动发领课短信 → 学员进领课页 → 领取试听权益（30 天）→ 引导加企微 → 去学习/看直播。
- **系统结果**：视频号订单记录（短信/领课/加微三状态）；线索流入线索池（渠道对接）。
- **异常分支**：未配置关联→订单同步但不发短信（R-SCRM-007）；短信失败→重发；未领课→复制领课链接补发。
- **验收**：AC-③-01~06。

### 5.4 路径④ 私域运营（商家端）

- **触发**：线索入池（视频号/直播小程序/手工/导入/OpenAPI）。
- **关键步骤**：线索池分配（商品×期次规则 > 通用规则，C-05 补配置页）→ 跟进（写跟进/加微/群跟进）→ 直播促到 SOP（人群筛选+排除条件+逐步骤触达）→ 转化回流订单 → 期次复盘看板。
- **系统结果**：线索状态机流转（含申请中审批态）；SOP 漏斗（目标→触达→预约→到场→支付）。
- **异常分支**：转移/无效/战败走审批；重复线索合并（优先级：手机号>订单号>姓名+渠道）；SOP 启动硬阻断校验。
- **验收**：AC-④-01~08（含 AC-④-06 重复线索合并）。

### 5.5 路径⑤ 平台侧治理（运营后台）

- **触发**：商家注册留资（register）→ 商务跟进。
- **关键步骤**：租户开通（套餐+费率+管理员+模板角色下发+应用授权）→ 内容/直播审核 → 交易发生 → T+1 对账（差异 5 处置）→ 商家确认 → 财务复核（双人）→ 打款 → 发票/台账 → 全局数据回流。
- **系统结果**：租户/对账单/结算单/提现单/发票状态机正确流转；平台费率收入台账。
- **异常分支**：对账差异（SLA 24h 升级）；申诉暂停账期结算；复核驳回退回；风控标记强制人工提现；停用租户（后台只读+C 端下架+结算走完）。
- **验收**：AC-⑤-01~08。
