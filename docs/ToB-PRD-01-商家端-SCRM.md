## 1. 模块定位与目标

**一句话**：帮商户管理员与助教/销售，把视频号等渠道进来的线索，按推广期次分配、领课承接、短信促到与跟进打标，跑通私域转化最短闭环。

对标现网「用户运营驾驶舱」通用能力；本期策略：**保留通用能力 → 简化艺博强绑定与完整工单 → 强化视频号 / 期次 / 促到**。

**本模块在总册中的位置**

- 路径③（视频号获客承接）：商品关联、领课短信/链接、订单状态回写、线索入库。  
- 路径④（私域运营）：期次与分配规则、跟进、直播促到 SOP、重复合并、基础营销工具。  
- 看板指标在「经营分析」模块展示；本模块保证订单/领课/加微/跟进数据可被统计。

## 2. 用户与典型场景

### 2.1 角色（产品视角）

| 角色 | 日常在本模块做什么 | 通常不做什么 |
|------|-------------------|--------------|
| 商户管理员 | 配渠道/期次/分配规则/欢迎语/活码/获客链接；看全部线索与视频号订单；重发短信；合并重复线索；建促到计划 | 跨租户；做小店/企微「授权配置页」（本期不做） |
| 助教 / 销售 | 看名下线索；写跟进、打标；执行促到相关待办；客户群发（按权限）；用素材/话术 | 默认不改全局分配规则、不删期次 |
| 平台运营 | 不在本模块操作 | 直接改商户线索（本期不做） |

**权限原则（摘要）**：商户隔离；手机号默认脱敏；无企微服务商身份时能力以企业内部应用可调用范围为限（详见 R-SCRM-001）。

### 2.2 场景故事（3–5）

**场景 A · 视频号下单后领课承接（路径③）**  
家长在视频号买了体验课。管理员在「视频号」页看到同步订单，确认已关联平台商品与领课短信模板；系统自动或手动发出领课短信。家长点链接领课并可被引导加微；后台订单与线索上的「领课 / 加微」状态同步更新，线索进入分配池。

**场景 B · 期次开营，线索自动分给助教（路径④前段）**  
管理员为「春季体验营」建好推广期次，并配置「视频号 × 体验课 × 该期次 → 助教组、轮询」。新线索入库后自动落到助教名下；无人可分或未命中规则的进「待分配」，管理员可批量指派。

**场景 C · 直播前短信促到**  
下场直播审核已通过。管理员在「直播促到 SOP」新建计划：圈选未到课/未加微等人群，加「开播前 1 小时」短信步骤并启动。助教在跟进里看到触达结果与未到课示意，对高意向继续私聊。

**场景 D · 助教日常跟进**  
助教打开「跟进管理 → 今日待跟进」，点开线索详情写跟进（方式/内容/下次跟进/意向），保存后列表「最近跟进」更新，线索从「已分配」进入「跟进中」。

**场景 E · 重复手机号合并**  
导入与视频号各产生一条同号线索。管理员在「重复线索」确认主从并合并；从线索关闭不可再分配，跟进记录挂到主线索。

## 5. 页面与交互（正文核心）

> 每个 P0 页面：目的 → 谁何时用 → 结构 → 主路径步骤 → 关键交互 → 空/载/败 → 跳转 → 权限差异。

### 5.1 视频号（`videos.html`）

- **页面目的**：完成视频号商品与平台商品的关联、领课短信配置，并承接订单（重发短信 / 复制链接）。  
- **谁在什么时候用**：管理员在开通视频号获客后配置；有新订单或短信失败时日常处理。  
- **页面结构（目标态 · 产品补全）**  
  - 顶区：标题「视频号」；次要操作不含「授权配置」验收项。  
  - **商品关联 Tab / 区**：已关联商品列表（外部商品、平台商品、自动发短信、引导加微、状态）+「关联商品 / 编辑领课配置」。  
  - **订单 Tab / 区**：订单列表（订单号、脱敏手机、商品、支付、短信、领课、加微）+ 行内「重发短信 / 复制领课链接 / 跳转线索」。  
  - 原型现状：仅「店铺授权 / 绑定橱窗」弹窗 → **原型超前授权 / 文档超前商品订单**（R-SCRM-020）。  
- **主路径操作步骤**  
  1. 进入「视频号」→ 打开商品关联 → 选择视频号商品与平台课/直播商品。  
  2. 填写领课短信模板（含链接占位）、勾选是否引导加微与自动发送 → 保存；Toast「配置已保存」。  
  3. 切到订单视图 → 看到同步订单及短信/领课/加微状态。  
  4. 短信失败或未发 → 点「重发短信」→ Toast 成功或失败原因留在行内。  
  5. 需要人工触达 →「复制领课链接」→ Toast「已复制」。  
- **关键交互细节**  
  - 未配模板时：订单可同步，但不可自动发短信，行内/空态提示去配置（R-SCRM-007）。  
  - 重发需可感知 loading；连续点击不重复计费（产品层：一次确认即可）。  
  - 「授权微信小店」按钮若仍出现在原型：标注不做，发布检查清单剔除。  
- **空态 / 加载 / 失败**  
  - 无关联商品：空态引导「先关联商品并配置领课模板」。  
  - 无订单：空态「暂无视频号订单，请确认部署侧同步」。  
  - 列表加载中骨架/表内 loading；短信失败展示原因文案。  
- **跳转关系**：订单 → 线索详情；商品配置可引用渠道活码。来自工作台「视频号/待处理订单」入口。  
- **权限**：管理员配置与重发；助教默认可只读订单或按权限复制链接（实现可配，默认管理员写）。

### 5.2 线索池（`leads.html`）

- **页面目的**：管理线索全量与待分配；配置分配规则（含期次入口）；基础导入导出。  
- **谁在什么时候用**：管理员日常分配与规则维护；助教查看/处理（按数据范围）。  
- **页面结构**  
  - 顶区：导出 / 导入 / 新建线索。  
  - Tab：待分配线索（P0）｜分配规则（P0）｜导入历史（P0）｜渠道对接 / 数据迁移 / 三方调试（P1 示意）。  
  - 筛选条：姓名手机、订单号、等级/阶段/意向、渠道、期次、归属人、加微/领课、时间；查询 / 重置 / 展开；批量分配（未勾选时 **disabled**）；更多（列展示等）。  
  - 列表 + 分页；行可打开详情抽屉；脱敏位「点击查看完整姓名/手机号」。  
  - 弹窗：新建线索、批量导入、分配线索；抽屉：列展示、线索详情、编辑。  
- **主路径操作步骤**  
  1. Tab「待分配」→ 勾选若干行 →「批量分配」可用 → 选归属人 → 确认 → Toast「已分配 N 条」。  
  2. 「新建线索」填姓名手机等 → 保存 → 列表出现；若命中规则则直接已分配。  
  3. 「导入」下载模板 → 上传 xlsx/csv → 开始导入 → 在「导入历史」看成功/失败，可下载失败明细。  
  4. Tab「分配规则」→ 新建规则（渠×品×期次、成员、轮询或上限）→ 启停。  
- **关键交互细节**  
  - 未勾选时批量分配按钮禁用。  
  - 脱敏点击：有权限则展开明文并记审计；无权限 Toast「无权限」。  
  - 列展示抽屉：姓名/手机固定勾选不可关。  
  - 删除线索需二次确认（原型已有 confirm）。  
- **空态 / 加载 / 失败**  
  - 无线索：引导「配置视频号商品或导入线索」。  
  - 从用户详情带参进入且无线索：卡片空态 +「创建跟进线索」。  
  - 导入格式错误：提示行号/原因；部分成功需明确数量。  
- **跳转**：详情可到跟进时间线；订单号可回视频号订单；规则命中后助教在跟进管理可见。  
- **权限**：助教默认可看名下；改全局规则、批量分配管理员为主。

### 5.3 跟进管理（`follow-ups.html`）

- **页面目的**：助教按「今日待跟进 / 逾期」等工作视图处理线索并写跟进。  
- **谁在什么时候用**：助教每日；管理员抽查或协助转移。  
- **页面结构**  
  - 顶区：导出、新建线索。  
  - 一级 Tab：归属组（原型文案「培育/K线/…」→ **产品改为可配置组名**，R-SCRM-015）。  
  - 二级 Tab（P0）：全部 / 我的线索 / 今日待跟进 / 逾期。  
  - 筛选 + 查询重置；批量「转移负责人」「调整阶段/等级」（未勾选 **disabled**）。  
  - 列表；抽屉「写跟进」「线索详情」；弹窗「转移负责人」「更多操作（无效/战败等）」「编辑线索」。  
- **主路径操作步骤**  
  1. 切到「今日待跟进」→ 点行打开详情 →「写跟进」。  
  2. 选跟进方式、填内容、可选意向/阶段/下次跟进/关联素材 → 保存 → Toast「跟进已保存」，列表时间更新。  
  3. （管理员）勾选 → 转移负责人 → 确认 → Toast 成功。  
- **关键交互细节**  
  - 写跟进内容为空不可保存（Toast 提示）。  
  - 「艺博士专家」等艺博强绑定入口：**禁用或不展示**（本期不做）。  
  - 无效/战败：P0 允许有权直接变更并填场景原因；「申请流」为 P1（S-5）。  
- **空态 / 加载 / 失败**：无待跟进空态「今日暂无待跟进」；保存失败 Toast 原因。  
- **跳转**：可回线索池；素材库选素材；用户模块打标协同。  
- **权限**：助教写名下；转移/看全部偏管理员。

### 5.4 直播促到 SOP（`live-invite.html`）

- **页面目的**：围绕一场直播配置短信促到步骤并执行，查看触达与未到课示意。  
- **谁在什么时候用**：管理员在直播前建计划；执行中可暂停/取消；助教查看结果。  
- **页面结构**  
  - 顶区：+ 新建直播促到 SOP（已结束场次时按钮 **disabled** + title 提示）。  
  - 筛选：关联直播、期次、渠道、客户阶段、加微/预约/到场/下单、状态。  
  - 列表：计划名、直播、步骤数、目标/触达/预约/到课/下单/成交、状态、操作。  
  - 大弹窗：新建/编辑 SOP（基础信息 + 人群筛选 + 步骤表）；步骤子弹窗；详情抽屉（启动/暂停/取消/编辑）。  
- **主路径操作步骤**  
  1. 新建 → 填计划名、选关联直播 → 设人群与排除项 → 添加短信步骤（时机+模板）→ 保存草稿。  
  2. 详情抽屉 →「启动」→ 状态变为待启动/执行中；系统按步骤发送。  
  3. 查看触达成功/失败；打开未到课名单示意；必要时暂停或取消（**confirm**）。  
- **关键交互细节**  
  - 保存校验：缺名称/直播/步骤 → Toast 拦截。  
  - 直播未审核通过：可存草稿，启动拦截并提示（R-SCRM-012）。  
  - 直播中限制：原型提示「仅可启动召回类步骤」。  
  - P0 执行通道=短信；外呼开关可展示但不验收充值（R-SCRM-013）。  
  - 删除步骤需 confirm。  
- **空态 / 加载 / 失败**：无计划引导新建；短信失败在触达明细可重试；详情找不到计划 Toast 并回列表。  
- **跳转**：关联直播详情/预约提醒；人群结果回线索。  
- **权限**：创建/启停管理员；助教只读结果为主。

---

### 5.5 重复线索（`leads-dup.html`）

- **页面目的**：发现同号/规则命中的重复线索并合并为主从。  
- **谁在什么时候用**：管理员在导入后或日常质检时。  
- **页面结构**：筛选（手机号/规则）+ 重复组列表；合并确认弹窗（选主线索、跟进人保留策略）。  
- **主路径**：选组 → 指定主线索 → 确认合并 → Toast → 从线索关闭且不可再分配；跟进挂主（R-SCRM-011）。  
- **关键交互**：跟进人冲突时强制选择；合并二次确认。  
- **空态**：无重复「暂无重复线索」。  
- **跳转**：合并后进主线索详情。  
- **权限**：合并仅管理员（或显式权限点）。

---

### 5.6 获客配置类（欢迎语 / 获客链接 / 渠道活码）

> 三个独立菜单页，交互模式相近，合并写清要点。

#### 5.6.1 欢迎语管理（`welcome.html`）

- **目的**：新客加好友后的欢迎文案配置。  
- **结构**：列表（名称、适用渠道、状态）+ 新建/编辑弹窗（名称、内容、渠道、启停）。  
- **主路径**：新建 → 填内容 → 启用 → 新客命中渠道时下发（实际下发受 E2 企微能力约束，界面先完成 CRUD）。  
- **空态**：引导「创建第一条欢迎语」。  
- **权限**：管理员写；助教只读或不可见配置。

#### 5.6.2 获客链接（`acquire-links.html`）

- **目的**：生成可追踪的获客链接（渠道/员工维度）。  
- **结构**：列表（链接名、渠道、归属员工、点击/加微等统计示意）+ 创建/复制链接。  
- **主路径**：创建 → 选渠道与员工 → 保存 →「复制链接」Toast。  
- **跳转**：统计可下钻到线索池筛选。

#### 5.6.3 渠道活码（`channel-livecode.html`）

- **目的**：配置企微渠道活码（成员、上限等），供视频号领课引导加微引用。  
- **结构**：列表 + 创建/编辑（渠道、成员、好友上限、状态）+ 下载/复制码。  
- **主路径**：创建并启用 → 在视频号领课配置中引用。  
- **权限**：管理员；依赖 E2 边界，能力不可用时降级提示且**不**引导去授权配置页。

---

### 5.7 客户群发基础（`mass-customer.html`）

- **页面目的**：向筛选出的客户发送基础群发（非朋友圈/群群发）。  
- **谁用**：管理员或有权限助教做活动通知。  
- **结构**：任务列表（名称、人群摘要、状态、成功/失败）+ 创建向导（选人群 → 写内容 → 立即/定时 → 提交）。  
- **主路径**：创建草稿 → 必选筛选条件 → 提交时**二次确认** → 执行中看明细。  
- **关键交互**：无筛选禁止提交（R-SCRM-014）；取消未发任务需确认。  
- **空态 / 失败**：空列表引导创建；失败明细可查看原因。  
- **权限**：按角色；全库误发双重拦截（产品规则 + 确认框）。

---

### 5.8 助销工具（素材库 / 快捷话术）

#### 5.8.1 助销素材库（`material.html`）

- **目的**：沉淀图片/链接/文件等助销素材，供跟进与群发引用。  
- **结构**：分类/标签筛选 + 素材卡片或列表 + 上传/启停。  
- **主路径**：上传 → 打标签 → 启用 → 在写跟进「关联素材」中选用。  
- **空态**：「上传第一个素材」。

#### 5.8.2 快捷话术库（`phrases.html`）

- **目的**：分组维护常用话术，跟进时快速插入。  
- **结构**：分组侧栏 + 话术列表 + 新建/编辑。  
- **主路径**：新建话术 → 选分组 → 保存；跟进抽屉中可选用（若原型未接全，产品要求可复制文案）。  
- **权限**：管理员维护；助教使用。

---

### 5.9 快捷任务（`quick-tasks.html`）

- **页面目的**：轻量指派待办（标题、处理人、状态），**不是**工单中心（R-SCRM-018）。  
- **结构**：任务列表 + 新建（标题、处理人、截止、备注）+ 完成/关闭。  
- **主路径**：管理员指派 → 助教在列表勾完成 → Toast。  
- **不做**：预警工单、进度看板、复杂流转。  
- **跳转**：可附线索链接（可选）。

---

### 5.10 规则配置（`rules-config.html`）

- **页面目的**：配置线索相关字典与去重/场景原因，去掉艺博业务名写死。  
- **结构**：Tab——意向等级｜线索等级｜线索阶段｜跟进事件｜去重规则｜场景原因；各 Tab 列表 + 新增弹窗（编码、名称、排序、状态等）。  
- **主路径**：在对应 Tab 新增/启停等级或原因 → 线索池与跟进筛选项立即（或刷新后）可用。  
- **关键交互**：删除需 confirm；编码/名称必填 Toast；去重规则默认匹配手机号以支撑合并。  
- **权限**：仅管理员。

---

### 5.11 渠道管理（`channel-mgmt.html`）

- **页面目的**：维护渠道主数据，供规则、活码、链接、线索来源引用。  
- **结构**：渠道列表（名称、类型、状态）+ 新建/编辑/启停。  
- **主路径**：新建「视频号」等渠道并启用 → 分配规则与获客配置可选用。  
- **空态**：引导先建渠道再配规则。  
- **权限**：管理员。

## 6. 跨页业务流程（路径③④ · 产品步骤）

### 6.1 路径③ 视频号获客承接

```
视频号下单(外部) → 订单同步 → [视频号页] 可见
    → 发领课短信 / 复制链接 → C 端领课(+加微引导)
    → 状态回写 → 线索入库 → 进入路径④分配
```

产品步骤：

1. （前置）渠道管理有「视频号」；视频号页完成商品关联与领课模板。  
2. 订单出现在视频号订单区；按配置自动或手动发短信。  
3. 用户领课/加微后，订单与线索状态更新；可从订单跳线索。  
4. 异常：短信失败可重发；重复领课提示已领取；授权页不作为操作步骤。

### 6.2 路径④ 私域运营

```
线索入库 → 匹配推广期次/分配规则 → 已分配
    → 跟进打标 → 直播促到 SOP(短信) → 看板指标(经营分析)
```

产品步骤：

1. 建推广期次与分配规则（线索池·分配规则 Tab）。  
2. 新线索自动分配或进待分配后批量分配。  
3. 助教在跟进管理写跟进；直播前管理员建促到 SOP 并启动。  
4. 重复号在重复线索页合并；经营分析看板查看获客/到课/转化（看板属其他模块）。

## 7. 业务规则（产品可读摘要）

完整条文见研发支撑 §5。产品验收常引用如下：

状态机原则（产品层）：线索从新建→已分配→跟进中，并可到转化/无效/流失/合并；加微与领课作为列表上的并行状态展示（终态细节见支撑文档与 S-3）。
